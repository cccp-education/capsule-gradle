== Décisions d'architecture

* *Docker FFmpeg reporté MVP1* — L'invocation FFmpeg reste locale
  (`ProcessRunner` wrapper `ProcessBuilder` via `ffmpegExecutablePath`) pour le MVP0.
  Le provisionnement Docker FFmpeg via KINSHASA (`container-provision-gradle`)
  est un candidat MVP1 (reproductibilité, CI/CD, isolation), mais c'est une
  fausse bonne idée pour MVP0 : ça ajoute une couche de complexité sans
  gain fonctionnel immédiat. Le pipeline formation doit d'abord être livré.
  Voir aussi : `container-provision-gradle` (KINSHASA, N0) pour l'infra
  Docker cross-borough existante.
