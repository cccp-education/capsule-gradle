  toleranceSecs: Double): ValidationResult`. Somme audio =
  `audioDurations.sum()`. Delta = `|videoDuration - sumAudio|`. Si
  `delta <= toleranceSecs` → `Valid(delta)`. Sinon →

  `Invalid(delta: Double, videoDuration: Double, sumAudio: Double,
  toleranceSecs: Double)`. Pattern `DeckContextValidator.ValidationResult`
  slider. `Invalid.message()` retourne un message actionable :

  `ValidationConfig(durationEnabled: Boolean = false, toleranceSecs:

  configs existantes sans `validation.durationEnabled` n'ajoutent pas
  de validation automatique). `toleranceSecs = 2.0` (tolérance
  réaliste : ffmpeg mux peut ajouter ~0.5-1s de silence, Playwright
  capture peut drift).
