== ✅ EPIC CAP-29 — Pipeline Traduction Vidéo Multi-Langue (Session 076 — Cadrage, Session 082 — TERMINÉ)

_Vision_ : Un deck source → 10 vidéos localisées en une tâche Gradle. Le pipeline

langue. CAP-29 crée le pont : un orchestrateur qui itère sur les langues cibles,
résout la voice TTS par langue, et génère un WebM localisé par langue.

_Domaine cible_ : `capsule.multilang` (nouveau domaine DDD, 7ème après `capsule.feed`,
`capsule.capture`, `capsule.tts`, `capsule.subtitles`, `capsule.manim`, `capsule.config`).
