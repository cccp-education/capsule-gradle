== Cible US-1 (détails BACKLOG)

- `GlossaryEntry(term: String, definition: String)` data class immutable
  (invariant fail-fast si `term` ou `definition` blank). Domaine
  `capsule.context`.
- `GlossaryContext(terms: List<GlossaryEntry>)` data class immutable
  (invariant `terms` non-empty si non-blank — un glossaire vide est légitime
  mais `GlossaryContext` n'est instancié que si ≥1 terme extrait).
- `GlossaryLoader` (object pur, mirror `PedagogicalScenarioLoader`) —
  `load(glossaryFile: File, maxTokens: Int): String`. Parse AsciiDoc
  `== Glossary` section + bullets `- term: definition`, rend `==== Official
  Glossary (glossary)\n<term>: <definition>\n...`, tronque via
  `ContextChannel.Docs.truncateToTokens(maxTokens)`. Missing file gracefully
  skipped (empty string). Malformed bullet (pas `- term: definition`)
  skipped. Non-Glossary section (`== Autre`) ignored.
- `CapsuleContext` 4ème champ `glossarySection: String = ""`, invariant
  ajusté `rendered.isBlank() == (channels.isEmpty() && scenarioSection.
  isBlank() && glossarySection.isBlank())`. Backward compat :
  `glossarySection = ""` (défaut) → tests existants inchangés.
- `CapsuleContextBuilder.build(composite, budget, scenarioSection="",
  glossarySection="", tracker=null)` étendu — append `glossarySection`
  après `scenarioSection` dans rendered (3 sections conditionnelles),
  `tracker.retainOnly` étendu `+= GLOSSARY_CHANNEL` si `trimmedGlossary.
  isNotBlank()`. Backward compat : `glossarySection = ""` (défaut).
- `DefaultCapsulePromptBuilder.buildGeneratePrompt` étendu — instruction
  line conditionnelle `if (state.augmentedContext.contains("Official
  Glossary"))` → appendLine "Use the official terminology defined in the
  Official Glossary section. Prefer glossary terms over generic synonyms."
  (pattern `Pedagogical Scenario` L50-55).
- Baby-step TDD : RED (tests → `Unresolved reference 'GlossaryLoader'`/
  `'GlossaryContext'`/`'GlossaryEntry'`/`'glossarySection'`) → GREEN →
  REFACTOR. ~10 unit :
  * `GlossaryLoaderTest` (~6) : parse bullets `- term: definition`, missing
    file skipped (empty string), empty glossary fallback (no `== Glossary`
    section), budget truncation, multi-term (3+ termes), malformed bullet
    skipped (pas `- term: definition`), non-Glossary section ignored.
  * `CapsuleContextTest` (~1) : invariant `glossarySection` (non-blank
    glossary + empty channels → non-blank rendered accepté).
  * `CapsuleContextBuilderTest` (~2) : `build` renders glossary section
    after scenario section (3 sections coexistent), `build` drops blank
    glossary section (backward compat), `build` with tracker tracks
    GLOSSARY channel when glossarySection non-blank.
  * `DefaultCapsulePromptBuilderTest` (~1) : `buildGeneratePrompt` contains
    "Use the official terminology" instruction when `augmentedContext`
    contains "Official Glossary", fallback generic prompt when absent.
