== Objectif

Réintroduire dans `capsule` le support **Fish Audio** (`https://api.fish.audio`),
un moteur TTS **cloud cloné** déjà utilisé par l'usine `prepa_electricite_complet`
(`foundry/private/prepa_electricite_complet/gen_audio.py`). Aujourd'hui capsule
n'a que des moteurs **locaux/offline** (`PiperTtsEngine`, `EspeakTtsEngine`) ou
un `NoOpTtsEngine` ; Fish apporte une **voix clonée de qualité** (registre
chaleureux) au prix d'un service **metered** (facturé à l'octet).

L'EPIC est **additif** : il branche un **4e `TtsEngine`** sur un port qui existe
déjà, sans modifier le comportement des moteurs existants (backward-compat
totale).

== Décisions

. **`fish-audio` = membre de `CapsuleConfig`** (demande pilote). Jackson mappe le
   bloc YAML `fish-audio` dans un membre `fishAudio`. Le trait d'union impose
   `@JsonProperty("fish-audio")` (identifiant Kotlin invalide sinon).
. **Le pool de clés est la valeur du membre** (shape de l'exemple) :
   `fish-audio:` → `List<FishAudioKey>` ; chaque entrée porte une `key`. C'est un
   **pool** : la 1re clé valide est utilisée, la rotation (repli 2e clé sur
   401/429) est possible plus tard — cohérent avec la doctrine maison (rotation
   des ports Ollama, `api-key-pool-gradle` N0).
. **Les paramètres non-secrets vivent dans `tts`** (demande pilote validée) :
   `tts.fishVoice` (voix clonée `reference_id`), `tts.fishModel`
   (défaut `speech-1.6`), `tts.fishFormat` (défaut `wav`), `tts.fishTemperature`
   (défaut `0.85`), `tts.fishTopP` (défaut `0.88`), `tts.fishEndpoint`
   (défaut `https://api.fish.audio/v1/tts`), `tts.fishAudioConfigFile`
   (défaut `fish.yaml`). Le **secret seul** reste isolé dans `fish.yaml`.
. **Le secret entre par `fish.yaml`, jamais par `capsule-context.yml`**
   (committé/scaffoldé). Le plugin charge `fish.yaml` (même `CapsuleConfigLoader`
   + substitution `${VAR}`) et **fusionne son unique membre `fishAudio`**. Fichier
   absent → `fishAudio` vide → moteur `fish` indisponible (dégradation propre,
   jamais d'échec). `fish_example.yaml` (committé, clé factice) = documentation
   du schéma.
5. **`FishAudioTtsEngine implements TtsEngine`** — `java.net.http.HttpClient`
   (JDK, **zéro dépendance**), corps JSON via Jackson, en-têtes `authorization:
   Bearer` + `model`, `format: wav` (comme `prepa` : le mp3 par défaut ajoute une
   compression), puis `AudioConversionUtil.wavToMp3`. `isAvailable` = présence
   d'au moins une clé non blanche. Retries bornés (transitoires) + écriture
   atomique (`.part` → `os.replace`).
6. **Jetons d'engine `fish` / `fish-audio`** dans `resolveTtsEngine()` →
   `FishAudioTtsEngine` ; indisponible + `strictMode` → erreur, sinon `NoOpTtsEngine`
   (patron `PiperTtsEngine`/`EspeakTtsEngine`).
7. **Rédaction obligatoire du secret** : `FishAudioKey.toString()` → `(key=***)`,
   et `CapsuleConfigLogger`/`CapsuleCompositeContextTask` ne doivent jamais
   exposer la clé (garde de test dédiée).
8. **Économie d'Encre** (Loi `AGENT.adoc`) : cache **indexé sur le texte dit**
   (sha1) — une phrase corrigée est forcément régénérée, une phrase inchangée est
   réutilisée sans appel meteron. Aligné sur le cache PRT-01 (`<file>.key`).
9. **Metered = accord pilote** : le dogfooding réel (US-5) exige l'autorisation
   pilote (comme S-158). **Aucun test n'utilise Fish Audio réel** : le moteur est
   **mocké** (seam HTTP injectable + stub `com.sun.net.httpserver.HttpServer`,
   patron des tests LLM) **ou** le test utilise `piper`/`espeak`/`NoOp` comme moteur.
   En CI, l'absence de `fish.yaml` rend `isAvailable()=false` → dégradation
   (jamais d'échec, jamais d'appel réseau). **Zéro appel réel à Fish en test.**
10. **Boundary** : capsule (N2) porte sa **première** authentification. Choix
   pilote « dogfood-first » : le secret vit dans un fichier gitignoré du
   consommateur. Le routage via le hub N1 (comme le LLM) est **écarté pour cette
   itération** (TTS hors périmètre codebase) — réouverture = EPIC distinct si un
   2e borough adopte Fish.
11. **English only** (code, Gherkin, commentaires) ; **zéro secret** commité ou
   loggé (Règle 6).
