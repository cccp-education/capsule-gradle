== Objectif

Résorber la **dette interne** de capsule : deux **god-objects** identifiés en code
review (S-194) —

|===
| Fichier | LOC | Responsabilités mélangées

| `capsule/CapsuleManager.kt` | **1115** | (a) enregistrement de ~20 tâches Gradle (≈890 l.) ; (b) 12 *factories* runtime `resolve*` + 3 helpers de chemins (≈210 l., `companion`)
| `capsule/CapsuleVideoTask.kt` | **1005** | task `@TaskAction` + résolveurs (TTS/Manim/viewport) + étapes pipeline (durées, TTS, Manim render/replace, capture séquentiel/parallèle, conversion, signature, burn-in) + helpers statiques

Ces god-objects sont de la **dette propre de capsule** — sans lien avec le rattrapage
hyperframes (le partage N1 `video-kernel` est sain).

== Cible (pattern éprouvé slider `SLD-6`)

=== `CapsuleManager` → enregistrements délégués par domaine

`CapsuleManager.registerTasks()` devient un **orchestrateur** qui délègue à des
**registrars par domaine** (classes/objets dédiés, `internal`), chacun portant les
`register*Task` de son domaine :

|===
| Registrar | Tâches

| `CapsuleCoreRegistrar` | extractSpeakerNotes, generateCapsuleScript, generateCapsule, generateCapsuleVideo, generateCapsuleVideoAllLanguages, deployCapsule, distributeCapsuleVideo
| `CapsuleContextRegistrar` | collectCapsuleContext, transformCapsuleContext, scaffoldCapsuleContext, collectCapsuleAugmentedContext, generateCapsuleContent, generateTranscript
| `CapsuleQcRegistrar` | validateCapsuleVideoDuration, preflightCapsuleContent, renderQcBoards, generateCapsuleChapters
| `CapsuleVoiceRegistrar` | verifyCapsuleVoice, selectBestVoiceTake
| `CapsuleViralRegistrar` | generateViralCampaign, renderViralVariants, renderViralThumbnails, renderViralSubtitles, validateViralCampaign, normalizeViralStoryboard
| `CapsulePodcastRegistrar` | generatePodcast
| `CapsuleAiRegistrar` | capsuleAiSmokeTest
|===

=== `CapsuleManager.companion` → `CapsuleFactory`

Les 12 `resolve*` (Manim, ffmpeg services, chapters) + `readScriptFiles`/
`resolveScriptDir`/`resolveDeckDir` constituent une **autre responsabilité** :
la sélection d'un adapter avec dégradation + `StrictModeGuard`. → objet `CapsuleFactory`.

=== `CapsuleVideoTask` → orchestration mince + domaines extraits

- **Résolveurs** (`resolveTtsEngine`, `resolveManim*`, `resolveViewport`) → `CapsuleVideoResolvers` (ou réutiliser `CapsuleFactory` + `TtsManager`).
- **Étapes de pipeline** → objets domaines purs là où possible (durées, capture déjà déléguée à `RevealJsEngineAdapter`) ; garder `CapsuleVideoTask` = séquence d'orchestration.
- **Helpers statiques** (`concatWebmFiles`, `createSingleSlideHtml`) → domaine (`capsule.adapter.revealjs`).
