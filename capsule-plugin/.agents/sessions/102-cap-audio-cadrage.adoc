== 12 Décisions architecturales

. *Nouveau domaine `capsule.audio` (10ème)* — `AudioPostProcessor`
  interface + `AudioPostProcessorImpl` (ffmpeg) + `NoOpAudioPostProcessor`
  (test fallback) + `AudioPostException`. Pas étendre `capsule` racine
  (responsabilité distincte : post-production audio).

. *`AudioPostConfig` data class (5 champs)* — `bgmEnabled: Boolean = false`,
  `bgmFile: String = ""`, `bgmLevel: Double = -18.0` (dB), `loudnessTarget:
  Double = -16.0` (LUFS EBU R128), `duckingEnabled: Boolean = false`.
  Defaults backward compat.

. *Section `audioPost` 10ème dans `CapsuleConfig`* — pattern
  `ValidationConfig`/`StrictModeConfig`.

. *4 sources pattern respecté* — ENV `CAPSULE_AUDIO_POST_*` < props
  `capsule.audioPost.*` < YAML `audioPost.*` < CLI
  `-Pcapsule.audioPost.*`. `mergeAudioPostConfig` (pattern
  `mergeValidationConfig` — `mergeBoolean` bgmEnabled/duckingEnabled,
  `mergeStr` bgmFile, `mergeDouble` bgmLevel/loudnessTarget).

. *`AudioPostProcessor` interface* — `process(videoFile, outputFile,
  config): Boolean` (retourne `false` si NoOp/échec — degraded mode garde
  original, pattern `VideoFormatConverter`). `isAvailable(): Boolean`,
  `name(): String`. `AudioPostException` pour erreurs critiques.

. *`AudioPostProcessorImpl` (FFmpeg)* — pipeline 3 étapes : (1)
  `loudnorm=I=-16:TP=-1.5:LRA=11` (EBU R128 single-pass, target -16 LUFS),
  (2) `amix` si `bgmEnabled && bgmFile exists`, (3) `sidechaincompress`
  si `duckingEnabled` (threshold -20dB, ratio 4:1, attack 5ms, release
  300ms).

. *`NoOpAudioPostProcessor` (test fallback)* — `process()` retourne `false`
  (caller garde original, degraded backward compat).

. *Factory `CapsuleManager.resolveAudioPostProcessor` (5ème)* — pattern
  `resolveFormatConverter` : `ffmpegPath = "noop"` → NoOp, unavailable +
  non-strict → NoOp, unavailable + strict → throw via `StrictModeGuard`,
  available → `AudioPostProcessorImpl`.

. *Wiring `CapsuleVideoTask.applyAudioPostIfEnabled`* — pattern
  `burnInSubtitlesIfEnabled` + `convertFormatIfEnabled` : si
  `!bgmEnabled && !duckingEnabled` → return (no-op), factory
  `resolveAudioPostProcessor`, `process(finalVideo, tmpFile, config)`,
  si succès rename tmpFile → finalVideo, si échec warn + garde original.
  Câblée `captureDeckSequential` (L492.5) + `captureDeckParallel` (L523.5).

. *`CapsuleExtension` étendu (5 properties)* — `audioPostBgmEnabled` +
  `audioPostBgmFile` + `audioPostBgmLevel` + `audioPostLoudnessTarget` +
  `audioPostDuckingEnabled`. `CapsuleConventions` étendu (5 champs).
  `pushConfigIntoExtension` push audioPost (pattern `validation`).

. *Économie d'encre (AGENT.adoc)* — skip si `!bgmEnabled && 
  !duckingEnabled` (défaut false → no-op), skip si BGM enabled mais
  `bgmFile` blank/missing → warn + degraded, skip si ffmpeg unavailable
  + non-strict → NoOp.

. *Cucumber runner dédié* `CapsuleAudioPostCucumberRunner` (pattern
  S-082 `@SelectClasspathResource` + filter `@audio and @post and not
  @wip and not @integration`). Steps `CapsuleAudioPostSteps` préfixés
  "audio post" (bug S-088 glue `capsule.scenarios` partagée).
  `CucumberTaskSpec("cucumberTestAudioPost")` (11ème cucumber dédié,
  12ème `CucumberTaskSpec`). *Pas de nouvelle tâche Gradle* — CAP-AUDIO
  est une étape de `CapsuleVideoTask`, pas une tâche séparée. Pas de
  clé `CapsuleMessages` ajoutée.
