== Scénarios BDD

. *Glossary injecté* : `glossaryFile` CLI param résout un glossary adoc (`== Glossary`
  + bullets `- term: definition`) → `==== Official Glossary (glossary)` section dans
  `augmented-context.txt` + termes `competence transversale`/`evaluation formative`
  présents + bullet `unrelated` de section `== Other Section` ignoré (parser
  `GlossaryLoader` ne lit que la section `== Glossary`).
. *Absent* : no `glossaryFile` configured → pas de section `Official Glossary`
  (backward compat strict — `glossaryFile = null` défaut → `resolveGlossarySection`
  retourne `""`).
. *Malformed* : glossary adoc sans `== Glossary` section (seulement `== Introduction`)
  → `parseGlossary` retourne empty list → `resolveGlossarySection` retourne `""` →
  pas de section `Official Glossary` (gracefully skipped fallback no-op).
