== Décision de renommage (S-095)

*Contexte* : capsule-gradle est public OSS (Apache 2.0). Le concept "SPD"
(Scénario Pédagogique Détaillé) est un format produit par un borough privé
non nommé publiquement. Capsule valide le *format* (`type=="SPD"` dans
metadata.json K-2), pas le borough producteur. La sémantique "SPD" ne doit
pas appartenir au vocabulaire capsule.

*Renommage appliqué* :
- `SpdContext` → `PedagogicalScenario` (data class, 6 champs)
- `SpdContextLoader` → `PedagogicalScenarioLoader` (object pur)
- `SpdContextLoaderTest` → `CapsuleScenarioLoaderTest` (10 unit tests)
- `CapsuleContext.spdSection` → `CapsuleContext.scenarioSection`
- Header rendu : `"==== SPD Pedagogical Context (spd)"` → `"==== Pedagogical Scenario (scenario)"`
- `DefaultCapsulePromptBuilder` détection textuelle :
  `contains("SPD Pedagogical Context")` → `contains("Pedagogical Scenario")`
- Instruction line : "Speaker notes must address the pedagogical scenario
  objectives. Target duration and prerequisites are specified in the
  Pedagogical Scenario section."

*Inchangé* : `metadata.json` validation `type=="SPD"` (c'est le format
externe K-2, pas le concept capsule). Pas de renommage du format externe.

*Fichiers renommés* (3, via `git mv`) :
