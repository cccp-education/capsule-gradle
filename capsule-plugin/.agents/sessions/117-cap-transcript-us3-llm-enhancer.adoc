== GREEN — 2 fichiers prod créés (domaine `capsule.transcript`)

. *`TranscriptLlmEnhancer.kt`* — interface port `fun enhance(template:
  String, plan: TranscriptPlan): String`. Pattern `CapsuleLlm` (port
  sync, le domaine ne connaît pas langchain4j). KDoc documente le
  fallback degraded (pattern `AudioPostProcessor.process` Boolean) —
  implémentations retournent le template original si LLM blank.

. *`ChatModelTranscriptEnhancer.kt`* — adapter `ChatModel`
  langchain4j. Pattern `ChatModelCapsuleLlm` : `model.chat(UserMessage.
  from(prompt)).aiMessage().text()`. Logique :
  - short-circuit si `template.isBlank()` → return template (no LLM
    call, économie d'encre)
  - prompt = `TranscriptPromptBuilder.buildEnhancePrompt(plan)`
  - response = `model.chat(UserMessage.from(prompt)).aiMessage().text()`
  - fallback degraded : `response.takeUnless { it.isNullOrBlank() }
    ?.trim()?.plus("\n") ?: template` — LLM blank/whitespace → template
    original (degraded mode, backward compat — le caller garde un
    AsciiDoc valide)
