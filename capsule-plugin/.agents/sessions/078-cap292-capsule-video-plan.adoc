== Objectif

Implémenter CAP-29.2 : créer le domaine `capsule.multilang` avec
`CapsuleVideoPlan` (data class immutable : liste d'entrées par langue) et
`CapsuleVideoPlanner` (object pur construisant le plan à partir des decks
traduits `<deckName>_<lang>-deck.html` + scripts `<deckName>_<lang>-script.txt`).

Baby-step TDD strict : RED → GREEN → REFACTOR. US purement unit (~18 tests

CAP-29.3 → functional, CAP-29.5 → cucumber).

== Décisions d'architecture

. *`CapsuleVideoEntry`* (data class immutable, domaine `capsule.multilang`) —
  4 champs : `deckFile`, `scriptFile`, `language: SupportedLanguage` (N0),
  `outputVideo`. Invariants à la construction (fail-fast) : deckFile exists,
  scriptFile exists, language code in `LanguageCatalog`.
. *`CapsuleVideoPlan`* (data class immutable) — `entries: List<CapsuleVideoEntry>`,
  invariant `entries.isNotEmpty()` (plan vide = misconfiguration upstream,
  fail-fast). Accès : `size()`, `isEmpty()`, `languages()`.
. *`CapsuleVideoPlanner`* (object pur) — `plan(deckDir, scriptDir, outputDir,
  targetLanguages: List<SupportedLanguage>): CapsuleVideoPlan`. Pour chaque
  langue : cherche `_<lang>-deck.html` dans deckDir, dérive le deckName
  (`kotlin-basics_fr-deck.html` → `kotlin-basics`), cherche le script
  `_<lang>-script.txt` dans scriptDir, calcule `outputDir/<deckName>_<lang>.webm`.
  Skip silencieux si deck ou script manquant (traduction partielle légitime).
  Fail-fast si aucune langue ne produit de paire deck+script.
. *Nommage aligné slider* — `<deckName>_<lang>-deck.html` + `<deckName>_<lang>-script.txt`
  → `<deckName>_<lang>.webm` (cohérent avec `slider.translateDeck` qui produit
  `<slug>_<lang>-deck.adoc`).
