== Objectif

Livrer **US-2** de l'EPIC `CAP-ENGINE-DECOUPLING` : extraire le **moteur**
reveal.js/Playwright de `CapsuleVideoTask` (1250 l.) derrière le **port neutre**
`capsule.kernel.VideoEngine`, avec un adapter `capsule.adapter.revealjs`. Le noyau
parle `segment`/`visual`/`engine` ; le vocabulaire reveal/slide/deck/Playwright
reste confiné à l'adapter. Additif, backward-compat.

=== Migration `CapsuleVideoTask` (1250 → **999 l.**, −251)

* `createSingleSlideHtml` / `concatWebmFiles` → **délégués** (`RevealJsDeckHtml` / `RevealJsEngineAdapter.concat`), signatures conservées (call-sites tests intacts).
* `resolvePlaywrightCapture` → construit l'adapter (`revealJsAdapter`) et délègue.
* `captureDeckSequential` / `captureSlideParallel` → capture déléguée à l'adapter, **post-processing conservé** dans la tâche (mix audio, burn-in sous-titres, audio post, conversion format — engine-agnostiques).
* `captureDeckParallel` inchangé (appelle `captureSlideParallel`).
* `injectAudio` → logique de string déléguée à `RevealJsDeckHtml`, I/O conservées.
* Suppression : `AUDIO_INJECT_SCRIPT`, `SINGLE_SLIDE_VISIBILITY_CSS`, `injectAudioSequentialFallback`, imports `Executors`/`Future`/`TimeUnit`/`TimeoutException`.
