== Objectif

Implémenter CAP-29.3 : la tâche Gradle `generateCapsuleVideoAllLanguages` qui
itère sur le `CapsuleVideoPlan` (produit par `CapsuleVideoPlanner` S-078),
appelle le pipeline TTS+capture par langue avec `ttsLanguage` adapté, et
génère `<deckName>_<lang>.webm` par langue. Économie d'encre : skip langue si
le WebM existe et est valide (probe duration > 0).

== Méthode

Baby-step DDD/TDD strict : RED → GREEN → REFACTOR, 2 niveaux de tests
(unit → functional). Zéro cucumber (US CAP-29.5). Non-régression stricte :
le pipeline mono-langue `CapsuleVideoTask` reste inchangé fonctionnellement.

== Décisions d'architecture

. *Domaine pur `CapsuleVideoAllLanguagesRunner`* (object, `capsule.multilang`)
  — orchestration itération + décision de skip = domaine testable sans Gradle.
  `run(plan, probeDuration: (File) -> Double, render: (CapsuleVideoEntry) -> Unit): List<CapsuleVideoEntry>`
  invoque `render` pour chaque entrée sans WebM valide, retourne les entrées
  rendues dans l'ordre du plan. `shouldRender(entry, probeDuration)` : true si
  le WebM n'existe pas OU probe ≤ 0 (artefact invalide re-rendu).
  Le travail lourd (TTS+capture) est injecté en callback — la frontière
  domaine/adaptateur Gradle reste nette.
. *Tâche `GenerateCapsuleVideoAllLanguagesTask : CapsuleVideoTask`* (adaptateur
  mince, `capsule.multilang`) — réutilise le pipeline mono-langue existant
  (CR-1 refactor) : `synthesizeTtsForScript`, `captureDeckSequential`/
  `captureDeckParallel`, `computeSlideDurations`, `generateSubtitles`, `injectAudio`.
  Résout `deckDir`/`scriptDir` via `CapsuleManager.resolveDeckDir/resolveScriptDir`
  (mêmes helpers que `CapsuleVideoTask.execute()`).
. *Adaptation TTS par langue* — avant chaque entrée : `ttsLanguage.set(code)`,
  `ttsVoice.set(resolved.piperModel)`, `espeakVoice.set(resolved.espeakVoice)`
  via `MultiLanguageResolver.resolve(code)`, puis `ttsEngine = null` pour forcer
  la re-résolution de l'engine (résolution cacheée par champ — reset nécessaire).
  `renderEntry` skip les langues sans mapping voice et les scripts vides.
. *Changements base `CapsuleVideoTask`* (zéro changement de comportement) :
  `execute()` → `open` (permet le @TaskAction override du sous-type),
  `resolveTtsEngine()` et `injectAudio()` → `internal` (réutilisables module).
  Seul @TaskAction restant = l'override du sous-type (pas de doublon Gradle).
. *targetLanguages* — défaut = `LanguageCatalog.supportedCodes()` (10 langues,
  contrats N0) mappé via `findByCode`. Le planner skip naturellement les langues
  sans paire deck+script → pas de DSL supplémentaire pour CAP-29.3.
. *Nommage* — `captureDeckSequential` écrit `outDir/<deckName>_<lang>.webm`
  (deckName du script traduit = `<deckName>_<lang>`) = `entry.outputVideo` du
  plan → alignement exact entre le fichier produit et le skip ink-economy.
