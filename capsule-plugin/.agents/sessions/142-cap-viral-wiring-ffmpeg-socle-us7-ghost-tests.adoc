== Décision clé — socle FFmpeg, pas Playwright

Le chemin viral force la stratégie `SCREENSHOT` (PNG par slide → encode FFmpeg
durée exacte → `concat` demuxer `-c copy`) via `ViralCaptureStrategy`. C'est la
décision S-138 rendue **exécutable** : `PLAYWRIGHT` (temps réel, non
déterministe) est écarté du viral ; `REMOTION` reste la couche d'enrichissement
(mouvement + Manim) composée **par-dessus** le socle. Une garde pure empêche la
dérive silencieuse vers Playwright quand `capsule.viral.enabled=true`.
