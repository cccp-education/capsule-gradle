== Décisions

. `ContextConfig` (pas `DocContextConfig`) — nom court aligné sur les autres
  sections (`InputConfig`, `TtsConfig`, etc.), le prefix `context.` dans la
  DSL est suffisant pour distinguer le périmètre.
. `mergeStrList` helper générique — réutilisable pour futures List<String>
  configs (CAP-GLOSSARY, CAP-AUDIO BGM files).
. `splitCommaList` internal — exposé pour le wiring (`CapsuleManager` l'utilise
  pour parser `capsule.context.docsGlobs` CLI).
. Lazy glob resolution via `project.provider { }` — la tâche est enregistrée
  avant `afterEvaluate`, l'extension est peuplée après. Provider diffère la
  résolution à l'exécution (task action), cohérent avec Gradle lazy config.
. `DocContextLoader.load(files, budget)` prend des `List<File>` pré-résolus,
  pas des globs — sépare résolution (Gradle wiring) du traitement (domain pur
  testable sans Gradle).
