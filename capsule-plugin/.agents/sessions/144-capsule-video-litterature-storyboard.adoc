== Contexte

Demande pilote : une revue de code + cadrage autour du borough capsule, apportant
un **squelette qui guide le storyboard**, dans la **littérature agentique**, dans
un fichier nommé « capsule vidéo » au format AsciiDoc. Le storyboard a besoin
d'un contexte répondant à (1) une **identité visuelle** (design system),
(2) un **QQOQCP**, et (3) un **fil conducteur narratif** cohérent entre séquences.

== Revue de code (au code réel)

Le domaine `capsule.viral` (CAP-VIRAL, S-140→S-142) sait *valider* un storyboard
mais ne lui donne **aucun contexte** :

* `ViralStoryboard` (`ViralStoryboard.kt:63`) — message/angle/beats/platform/
  language/durée ; **pas** de QQOQCP, identité visuelle ni fil conducteur.
* `StoryboardBeat` (`:19`) — séquence isolée (role, intent, durée, rendu,
  manimScene, asset) ; **aucune** transition/lien vers la suivante.
* `ViralStoryboardBuilder` (`:22`) — squelette pauvre (`== Angle` + `== Beats`).
* `ViralStoryboardValidator` (`:56`) — gate de **forme** (hook/CTA, ±20 %, ≤ 10 s),
  jamais de **cohérence narrative**.
* `Capsule.jsx:237` (`PAGE_BACKGROUND`) — fond de composition **codé en dur**,
  **aucun** branchement à une charte.

Recoupe `CAPSULE_PEDAGOGIQUE.adoc` § 4.1 (recette 3C) : la chaîne part du
**QQOQCP** → **identité visuelle** → **storyboard** ; le storyboard CAP-VIRAL
n'accueille que la dernière étape.
