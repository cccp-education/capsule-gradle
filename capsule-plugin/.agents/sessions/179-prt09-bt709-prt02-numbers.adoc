== R1 — PRT-09 : colorimétrie BT.709 (objet pur + wiring)

Le review `prepa` (PRT-09) prévoyait la colorimétrie **bt709** ; l'encode MP4 de capsule
ne l'émettait pas.

* **Objet pur** `capsule.Mp4ConversionCommand.buildArgv(ffmpegPath, input, output, bt709)`
  (mirror `AudioPostCommand`/`SubtitleBurnInCommand`) : argv ffmpeg `libx264/aac/+faststart` ;
  quand `bt709=true`, ajoute `-color_primaries bt709 -color_trc bt709 -colorspace bt709`.
  Quand `false`, argv **byte-identique** à l'historique (backward compat).
* `VideoFormatConverterImpl(ffmpegPath, bt709)` consomme l'objet pur (fin de l'argv inline).
* **Config 4 sources** : `OutputConfig.bt709` ; `mergeOutputConfig` (`mergeBoolean`) ;
  loaders env (`CAPSULE_OUTPUT_BT709`) + props (`capsule.output.bt709`) ;
  `CapsuleExtension.outputBt709` ; `CapsuleConventions.outputBt709=false` ;
  `CapsulePlugin.pushConfigIntoExtension` ; `resolveFormatConverter(..., bt709)` ;
  `CapsuleVideoTask.convertFormatIfEnabled` passe le flag.
* **Tests** : `Mp4ConversionCommandTest` (3 unit : default sans flags, bt709 présent,
  ordre avant la sortie) + `CapsuleConfigMergerTest` (+3 : défaut false, props, CLI>YAML) ;
  BDD `capsule_format.feature` +2 scénarios (bt709 activé / désactivé) + 4 steps.

== R2 — PRT-02 : nombres en lettres (Kotlin pur, zéro `num2words`)

Le QC voix `prepa` développait les nombres (`num2words`) avant comparaison ; le
`TextNormalizer` de capsule ne le faisait pas → faux positifs WER sur les nombres.

* **Objet pur** `capsule.voice.NumberSpeller` — `spell(text, language="fr")` remplace
  chaque entier par son orthographe française (`french(n)` : unités/dizaines/`soixante-dix`/
  `quatre-vingts`/centaines avec pluriel/`mille` invariable/millions/milliards). Autres
  langues → identité.
* Intégré dans `FidelityScorer.score(expected, transcribed, language="fr")` : les deux
  côtés sont épelés avant normalisation → « il y a 42 pommes » ≡ « il y a quarante deux pommes ».
  `TextNormalizer` **inchangé** (contrat `keeps digits` préservé).
* **Tests** : `NumberSpellerTest` (7 unit : irrégularités 70/80/90, pluriels, milliers,
  phrase, autre langue, scoring fidélité à WER 0) ; BDD `capsule_voice_quality.feature`
  +1 scénario (aucun step neuf).
