== Décisions techniques

. `SlideType` migre vers `capsule.feed` (était dans `capsule`). Un seul enum.
. `CapsuleScript.segments` (était `slides` côté capsule) — aligné sur feed.
. `CapsuleScriptWriter` n'émet pas `[html]` par défaut (compatibilité format
  historique — le reader l'accepte mais le writer ne l'émet pas pour préserver
  les tests existants et le contrat slider-side).
. `CapsuleScriptReader.read` fallback filename quand header manquant (port
  `parseScript` behavior).
. `CapsuleExtension`/`CapsuleConventions` restent dans `capsule` (pas du modèle
  métier — configuration Gradle).
