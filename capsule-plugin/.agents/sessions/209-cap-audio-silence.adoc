== Mission

Le pipeline vidéo peut produire un MP3 **techniquement valide mais muet**
(NoOp TTS, export audio cassé, mauvais fichier). Le QC voix existant
(`verifyCapsuleVoice`) ne détectait ce cas que via l'ASR : sans ASR, le rapport
restait `degraded` et le take muet passait. US-1 ajoute une détection de
silence **indépendante de l'ASR**, sur l'enveloppe RMS déjà extraite par
`AudioEnvelopeExtractor`.

== Constat (audit)

* `VoiceVerifier.degraded(...)` marquait **tous** les takes `Degraded` — un
  audio muet n'était jamais un échec sans ASR.
* `VoiceQualityGate` ne connaissait que WER / surplus / SNR ;
  `AudioEnvelopeExtractor` + `RmsEnvelope` existaient déjà (US-2) mais
  l'enveloppe n'était exploitée que pour le SNR.
* Un audio muet produit un `snrDb = -Infinity` (log de zéro) : signal non
  fini, inutilisable comme verdict exploitable.

== Décisions

. **DDD — domaine pur** : `capsule.voice.AudioSilenceDetector` +
   `SilenceAnalysis` (aucun I/O, aucun ASR, aucun ffmpeg).
. **Détection sur le pic RMS**, pas sur la fraction silencieuse : une narration
   normale contient des pauses ; seul l'absence totale de signal (ou un
   envelope vide) est un silence. `silentFraction` reste exposé pour le
   diagnostic.
. **Seuil** `0.001` RMS normalisé (~-60 dBFS), constante du domaine
   (`DEFAULT_RMS_THRESHOLD`). Pas de nouvelle source de config pour cette US.
. **Indépendance ASR** : `VoiceVerifier.degraded` accepte désormais un
   `envelopeProvider` ; un take muet devient `Fail(["silent-audio"])` même si
   l'ASR est absent. Le rapport reste `degraded = true` pour la moitié fidélité
   non vérifiée.
. **Ordre des gates** : `VerifyCapsuleVoiceTask` vérifie `hasFailure` **avant**
   le retour dégradé — un défaut de contenu (silence) ne peut pas être masqué
   par l'absence d'ASR.
. **Pas de publication / pas de bump** : US additive et rétro-compatible ;
   `silent-audio` n'apparaît que lorsque l'enveloppe est disponible.
. **N1 non modifié** : promouvoir `AudioSilenceDetector` dans `video-kernel`
   exigerait une publication Central (Règle 2) ; hyperframes expose déjà
   `film_silent` côté CLI. La factorisation N1 reste un candidat ultérieur.

== Effet produit

Un capsule muette échoue désormais `verifyCapsuleVoice` (opt-in) avec
`silent-audio`, **même sans ASR**. Le rapport JSON expose la raison ; le seuil
reste le défaut du domaine. C'est une garde de contenu, pas un prérequis de
`check` (la tâche reste opt-in via `voice.verifyEnabled`).
