== Audit code (US-0)

- `ScreenshotCaptureImpl` (`PlaywrightManager.kt:135`) implémente `PlaywrightCapture`
  mais n'est **jamais câblé** dans `CapsuleVideoTask.resolvePlaywrightCapture()`
  (`CapsuleVideoTask.kt:176`) — qui ne construit que `PlaywrightCaptureImpl` ou
  `NoOpPlaywrightCapture`.
- `ScreenshotCaptureImpl.capture()` ne gère qu'**une slide**
  (`slideDurations.firstOrNull()`), pas un deck multi-slides.
- `CaptureConfig` (`CapsuleConfig.kt:39`) n'a pas de champ `strategy`.

== Décisions architecturales (5)

. `CaptureStrategy` enum type-safe (2 valeurs `PLAYWRIGHT`/`SCREENSHOT`, défaut
  `PLAYWRIGHT` backward compat). Companion `fromString` case-insensitive, fallback
  `PLAYWRIGHT` pour unknown/blank.
. `ScreenshotCaptureImpl` étendu **multi-slide** — boucle screenshot/png par slide
  + ffmpeg png→webm par slide + concat webm via ffmpeg concat demuxer. Contrat
  `PlaywrightCapture.capture()` inchangé (même signature).
. `CaptureResolver` object pur (factory) — dispatch `when(strategy)` injectant
  `PlaywrightFactory`/`ScreenshotFactory` (testable sans I/O). `StrictModeGuard`
  réutilisé (screenshot absent → fail si strict).
. `capture.strategy` 4 sources (pattern CapsuleConfigMerger) —
  ENV `CAPSULE_CAPTURE_STRATEGY` < props `capsule.capture.strategy` < YAML
  `capture.strategy` < CLI `-Pcapsule.capture.strategy`.
. `ScreenshotCaptureImpl` = alternative **configurable**, pas remplacement —
  `PLAYWRIGHT` reste défaut (backward compat, économie d'encre).
