== Décisions architecturales (US-1)

. *GlossaryEntry/GlossaryContext immutables* — data classes invariant
  fail-fast. GlossaryContext liste ordonnée (pas map — l'ordre a une valeur
  pédagogique, pattern BACKLOG US-0 décision 2).

. *GlossaryLoader object pur* — mirror `PedagogicalScenarioLoader` (3ème
  loader du domaine `capsule.context` après `DocContextLoader` et
  `PedagogicalScenarioLoader`). `load(file, maxTokens): String` — pure, no
  I/O wiring, no Gradle. Format AsciiDoc natif (`== Glossary` + bullets
  `- term: definition`), parsing purement textuel (split sur `== Glossary`,
  extract bullets, split sur premier `:`). Pas de dépendance AsciidoctorJ.

. *Truncation via `ContextChannel.Docs.truncateToTokens`* — le variant
  Docs est sémantiquement proche (corpus documentaire), réutilise le N0
  sans bump codebase-contracts (pattern `PedagogicalScenarioLoader` L67).
  Budget 5% = 400 tokens (décision US-0).

. *`CapsuleContextBuilder.buildRendered` refactor* — le `when` existant
  (4 cas channelBlock/trimmedScenario) a été refactoré en
  `listOf(...).filter { isNotBlank }.joinToString("\n\n")` pour supporter
  3 sections conditionnelles sans duplication. Le comportement est
  identique pour les 2 sections existantes (tests scenarioSection
  préservés 100% — 7 tests VERT).

. *Backward compat strict* — `glossarySection = ""` (défaut) → tous les
  appelants existants (`CollectCapsuleAugmentedContextTask` L132) inchangés.
  Tests existants `CapsuleContextBuilderTest` (scenarioSection L196-255)
  préservés sans modification (seuls les tests d'invariant
  `CapsuleContext` reject orphan ont été ajustés pour le nouveau 4ème
  paramètre `glossarySection = ""`).

. *Arguments nommés sur `build()`* — l'appel existant
  `CapsuleContextBuilder.build(composite, budget, scenarioSection, tracker)`
  positionnel a été migré en arguments nommés pour éviter la fragilité
  lors de l'insertion du nouveau paramètre `glossarySection` entre
  `scenarioSection` et `tracker`. Le wiring US-2 étendra avec
  `glossarySection = resolveGlossarySection(budget)`.
