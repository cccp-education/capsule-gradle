== Livrables

=== Domaine `capsule.audio` enrichi (4 fichiers prod + 1 exception)

1. `src/main/kotlin/capsule/audio/AudioPostProcessor.kt` — interface
   `process(videoFile: File, outputFile: File, config: AudioPostConfig):
   Boolean` (degraded mode retourne `false`, pattern
   `VideoFormatConverter`), `isAvailable(): Boolean`, `name(): String`.
   KDoc documente le pipeline 3 étapes (loudnorm EBU R128 + amix BGM +
   sidechaincompress ducking) et le pattern factory
   `resolveAudioPostProcessor`.

2. `src/main/kotlin/capsule/audio/AudioPostProcessorImpl.kt` — impl
   FFmpeg `loudnorm=I=${loudnessTarget}:TP=-1.5:LRA=11` EBU R128 +
   `volume=${bgmLevel}dB + amix=inputs=2:duration=first:dropout_transition=0`
   BGM (si `bgmEnabled && bgmFile exists`) +
   `sidechaincompress=threshold=0.1:ratio=4:attack=5:release=300`
   ducking (si `duckingEnabled && bgmEnabled` — ducking sans BGM
   ignoré, meaningless). `NoOpAudioPostProcessor` (returns `false` —
   degraded garde original, pattern `NoOpVideoFormatConverter`).
   BGM file blank/missing → degraded `false` (warn + garde original,
   économie d'encre).

3. `src/main/kotlin/capsule/audio/AudioPostCommand.kt` — object pur
   (pattern `FormatConversion`) — `buildFilterGraph(config, hasBgmInput):
   String` (loudness-only / loudness+BGM `[0:a]loudnorm[voice];[1:a]
   volume[bgm];[voice][bgm]amix[aout]` / loudness+BGM+ducking `...
   sidechaincompress[ducked];[voice][ducked]amix[aout]` / ducking-
   without-BGM ignored → loudness-only fallback) + `buildArgv(videoFile,
   bgmFile, outputFile, config, ffmpegPath): List<String>` (BGM =
   2ème `-i` + `-filter_complex` + `-map 0:v -map [aout]`, no-BGM =
   `-af` loudnorm only, `-c:v copy -c:a libvorbis -shortest`).

4. `src/main/kotlin/capsule/audio/AudioPostException.kt` — RuntimeException
   pour erreurs critiques (pattern `BurnInException`).

=== Factory `resolveAudioPostProcessor` (5ème factory `resolve*`)

`CapsuleManager.resolveAudioPostProcessor(ffmpegPath: String = "ffmpeg",
strict: Boolean = false): AudioPostProcessor` — pattern
`resolveFormatConverter` : `noop`→NoOp, unavailable+non-strict→NoOp,
unavailable+strict→throw via `StrictModeGuard.requireAvailable`, available
→Impl. 5ème factory `resolve*` (après `resolveManimVideoMixer`,
`resolveManimEngine`, `resolveSubtitleBurnInService`,
`resolveFormatConverter`). `StrictModeGuard.requireAvailable` 8ème
branche.
