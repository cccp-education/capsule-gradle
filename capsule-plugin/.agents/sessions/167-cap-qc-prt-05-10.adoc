=== PRT-05 — Pré-vol contenu avant dépense TTS

tout appel TTS facturé.

* **Pur** : `capsule.qc.ContentPreflight` — `Severity` (ERROR/WARNING), `PreflightFinding`,
  `ForbiddenForm(pattern, reason)`, `PreflightRules(maxNoteChars=500, forbidden=[markdown])`,
  `ContentPreflight.check(slides, rules)`. Contrôles : note trop longue (WARNING), note
  dupliquée insensible casse/espaces (WARNING), forme interdite (ERROR). (`SlideSegment`
  garantit déjà titre et note non vides → pas de contrôle `blank`.)
* **Tâche** : `preflightCapsuleContent` (groupe `verification`), opt-in
  `qc.preflightEnabled` ; lit les scripts (`CapsuleManager.resolveScriptDir`/`readScriptFiles`),
  log les findings, échoue sur ERROR (et sur WARNING en `strictMode`). Config `QcConfig`
  (`qc.preflightEnabled`, `qc.maxNoteChars=500`) sur les 4 sources + push.
* **Tests** : `ContentPreflightTest` (8 unit) + `PreflightCapsuleContentFunctionalTest`
  (3 fonctionnels : défaut skip, clean OK, forbidden échoue) + `capsule_content_preflight.feature`
  (3 scénarios `@qc @preflight`, runner dédié 32e `cucumberTestContentPreflight`) +
  test merger.

=== PRT-10 — Publication : chapitres YouTube texte + description

Porté de `prepa_electricite_complet/subs.py` (`chapitres.txt`) et `description.py` (garde
chevrons).

* **Pur** : `capsule.chapters.YouTubeChaptersFormatter` (`format(entries)` → lignes
  `M:SS Titre` / `H:MM:SS Titre` ; `formatTimestamp`) + `capsule.publish.VideoDescriptionBuilder`
  (`build(title, chapterLines, tags, header)` → `Result(text, strippedForbiddenChars)`,
  retire les caractères que YouTube refuse `<`/`>`).
* **Câblage** : `GenerateCapsuleChaptersTask` écrit désormais `chapters.txt` (format
  YouTube) et `description.txt` (titre + chapitres + tags, sans caractères interdits) à
  côté de `chapters.json` et des cartes.
* **Tests** : `YouTubeChaptersFormatterTest` (4 unit) + `VideoDescriptionBuilderTest`
  (4 unit) + scénarios ajoutés à `capsule_chapters.feature` (runner `@chapters` existant :
  `chapters.txt` au format YouTube + `description.txt` sans `<`/`>`).

  déjà `ViralThumbnailBuilder`/`RenderViralThumbnailsTask`) — item optionnel ultérieur.
