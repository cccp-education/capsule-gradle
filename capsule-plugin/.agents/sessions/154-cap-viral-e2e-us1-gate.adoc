== US-1 — Delivery gate (manifeste ↔ fichiers)

Baby-step DDD/TDD/BDD, domaine pur d'abord, câblage = adaptateur mince.

=== Domaine (unit)

* `capsule.viral.ViralCampaignGate` (objet pur) : `verdict(bundles, exists)` →
  `ViralCampaignGateResult` sealed (`Valid` / `Invalid(missing)`). Vérifie chaque
  `videoFile` (obligatoire) et `thumbnailFile` non-blanc (optionnel — un thumbnail
  vide est un rendu valide mais plus faible). Agrège les manques en ordre de bundle.
* `CampaignBundleSerializer.parseManifest(json)` — inverse exact de
  `toManifestJson` (round-trip) ; refuse un JSON non-tableau (fail-fast).
* `ViralCampaignGateTest` : 10 tests (valid, missing video, missing thumbnail,
  blank thumbnail ignoré, agrégation ordonnée, campagne vide, invariant `Invalid`,
  round-trip 2 bundles, manifeste vide, non-tableau rejeté).

=== Câblage (functional)

* `ValidateViralCampaignTask` (groupe `verification`, `dependsOn
  renderViralVariants`) : lit `viral-campaign.json`, reconstruit les bundles,
  appelle la gate. Manifeste absent/malformé → warning ou échec en strict ;
  asset manquant → warning (dégradé) ou échec (strict).
* `CapsuleManager.registerValidateViralCampaignTask` + convention
  `manifestFile` (`build/capsule/viral/viral-campaign.json`, tolérante si absent).
* `ValidateViralCampaignFunctionalTest` : 5 tests TestKit (registration groupe
  `verification`, skip par défaut, assets présents → OK, manquant + strict →
  échec, manquant non-strict → avertissement). Chaîne `renderViralVariants`/
  `generateViralCampaign` exclue (`-x`) : gate testée en isolation.

=== BDD (cucumber)

* `capsule_viral_gate.feature` `@viral-gate` : 5 scénarios (assets présents,
  vidéo manquante, thumbnail manquant, thumbnail vide non-violation, round-trip
  manifeste) — pur domaine, prédicat d'existence simulé.
* `CapsuleViralGateSteps` (préfixés « campaign gate »/« campaign manifest »,
  bug S-088) + `CapsuleViralGateCucumberRunner` (pattern S-082).
* `CucumberTaskSpec("cucumberTestViralGate")` câblé + `full-tests.yml`.
