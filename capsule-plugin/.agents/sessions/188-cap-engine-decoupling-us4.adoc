== Objectif

Livrer **US-4** de l'EPIC `CAP-ENGINE-DECOUPLING` : garantir que le **noyau
engine-agnostique** `capsule.kernel` reste isolé, par une **garde d'architecture**
(test frontière, pattern `OssVocabularyGuardTest` / `ProcessMigrationGuardTest`).
Corrige une fuite de vocabulaire révélée par la garde.

== Méthode

Baby-step DDD/TDD/BDD strict (unit → fonctionnel → cucumber). **Local = Build /
Tests = CI** (compiles ×3 + `assemble` + `validatePlugins` uniquement en local).

== Livrables

=== Neutralisation d'une fuite de vocabulaire (kernel)

`VideoRenderRequest.slideDurations` (introduit en US-2) violait D7 (« le noyau
parle segment/visual/engine, jamais slide »). Renommé **`segmentDurations`**
(kernel + adapter `RevealJsEngineAdapter` + named-args `CapsuleVideoTask`) ;
l'adapter traduit vers `PlaywrightCapture.capture(slideDurations = …)` (paramètre
de l'interface de capture, hors noyau). Ajout d'un invariant kernel
(`segmentDurations.size == segments.size`).

=== Garde d'architecture (créée)

[cols="1,3", options="header"]
|===
| Fichier | Rôle
| `capsule/ci/KernelBoundaryAudit.kt` | Audit statique partagé : (1) **imports** du noyau limités à `java.`/`kotlin.`/`contracts.`/`capsule.kernel.` ; (2) **vocabulaire de code** (commentaires retirés) sans `slide`/`deck`/`reveal`/`playwright`/`data-audio`/`data-capsule-slide`/`asciidoc`/`processbuilder`/`org.gradle`.

`contracts.i18n.*` (purs, sans Gradle/Playwright) — conforme à D5 (le noyau peut
dépendre de contrats purs, pas d'une lib utilitaire).
