== Livré

* **Pure** `capsule.a11y.AudioDescriptionMixCommand` :
  - chaque cue est un input (`[i+1:a]volume=<level>dB,adelay=<ms>|<ms>[dN]`) ;
  - les cues sont mixés (`amix … duration=longest`) avant le ducking ;
  - `[0:a]asplit=2[voice][key]` ; `[desc][key]sidechaincompress=…[ducked]` ;
  - `[voice][ducked]amix=…,asplit=2[aout][asep]` — un pad de filtre est
    mono-usage, d'où le `asplit` avant les deux sorties ;
  - argv unique ffmpeg : vidéo mixée (`[aout]`) + piste `<deck>-audiodesc.m4a`
    (`[asep]`, AAC).
* **Wiring** `CapsuleVideoTask.applyAudioDescriptionIfEnabled(finalVideo,
  audioDir, slides)` :
  - opt-in `a11y.audioDescriptionEnabled` ;
  - script chargé (`AudioDescriptionScriptParser.load`) ;
  - **fenêtres de narration** dérivées des durées `slide-NN.mp3` (le mix audio
    est leur concaténation, cf. `mixAudioWithVideo`) ;
  - `AudioDescriptionPlanner.plan(..., totalSeconds = fin de narration)` ;
  - synthèse TTS par cue (moteur existant), skip si indisponible/inéchec ;
  - mix + remplacement atomique + piste séparée ;
  - **dégradation silencieuse** à chaque absence (script vide, plan vide, TTS
    indisponible, ffmpeg en échec) : la vidéo garde sa narration.
* Appelé **après** `mixAudioWithVideo` et **avant** l'audio-post (le loudness
  EBU R128 s'applique alors au mix final), dans les deux chemins de capture.
* **Config** section `a11y` : `audioDescriptionEnabled` (false),
  `audioDescriptionFile` (""), `audioDescriptionLevelDb` (-6.0) — 4 sources +
  `CapsuleExtension`/`CapsuleConventions`/`pushConfigIntoExtension`.

'''
