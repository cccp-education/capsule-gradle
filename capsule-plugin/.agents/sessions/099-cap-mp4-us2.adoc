== Objectif

Implémenter la couche de conversion de format WebM→MP4/H.264 et le wiring
post-capture. `VideoFormatConverter` (FFmpeg libx264+aac+faststart) avec NoOp
fallback. `FormatConversion.convertIfNeeded` dispatch pur sur `OutputFormat`
(WEBM/MP4/BOTH) avec économie d'encre (skip si `.mp4` existe ET probe>0).
`DistributeCapsuleVideoTask` étendu pour filtrer selon `output.format`.

== Décisions architecturales

. *`VideoFormatConverter` interface (pas object)* — pattern
  `SubtitleBurnInService` : interface + Impl + NoOp. Permet tests sans
  ffmpeg (NoOp fallback) + strict mode via factory.
. *`FormatConversion` object pur séparé* — dispatch logique isolé du
  converter (testable sans I/O, injecte `probeDuration` lambda). Pattern
  `ScreenshotPlanner` (argv builders purs).
. *Factory `resolveFormatConverter` dans `CapsuleManager`* — pattern
  `resolveSubtitleBurnInService` (4ème factory `resolve*` : ManimEngine,
  ManimVideoMixer, SubtitleBurnInService, FormatConverter). `StrictModeGuard`
  réutilisé (7ème garde branché).
. *Économie d'encre préservée* — skip transcode si `.mp4` existe ET
  `probeDuration(mp4) > 0` (AGENTS.adoc "Loi de l'Économie d'Encre").
  Skip WebM→MP4 si format==WEBM (no-op). Skip distrib si destination existe
  (déjà S-087).
. *Wiring post-burnIn* — `convertFormatIfEnabled` appelé après
  `burnInSubtitlesIfEnabled` dans les 2 chemins (sequential + parallel).
  Log `CAPSULE →` pointe vers le fichier produit (WebM ou MP4).
. *`DistributeCapsuleVideoTask.format` Property* — résolu depuis le merger
  (push `merged.output.format.name`), CLI `-Poutput.format` override.
  Filtre `.webm`/`.mp4`/both selon `OutputFormat.fromString`.
