== Contexte

Suite d'US-1b/US-2. L'orchestration (S-147) capturait le deck **par variante** :
pour N variantes (langue × plateforme) partageant le **même** deck portrait et les
**mêmes** durées, c'était N captures identiques — un gaspillage. US-3 rend le
batch **réel et économique** : capturer **une fois**, répliquer à chaque variante.

== Livrable — batch capture-once

=== Domaine pur `capsule.viral` — `ViralVariantRenderer.render`

Signature revue (2 seams I/O injectés, logique pure) :

[source,kotlin]
----
fun render(
    plan: ViralVariantRenderPlan,
    isRenderable: (File) -> Boolean,
    capture: (target: File) -> Boolean,
    replicate: (source: File, target: File) -> Boolean,
): ViralRenderResult
----

* skip des `<id>.mp4` déjà valides (Économie d'Encre) ;
* **capture une seule fois** dans le premier variant *pending* (`capture`) ;
* **réplique** cette vidéo à chaque autre variant (`replicate`) ;
* échec de capture → tout le *pending* en échec ; échec de réplication → variante
  en échec (le batch ne casse pas).

L'interface `ViralVariantRender` (per-entry) est **retirée** — remplacée par les
deux lambdas, ce qui rend la capture unique explicite et testable.

=== Câblage `RenderViralVariantsTask`

* `captureDeckToTarget` — capture le deck (socle FFmpeg `SCREENSHOT`) → transcode
  MP4 → **gate durée** (US-2). Dossier de travail `_capture-work`.
* `replicateVideo` — copie fichier (`copyTo(overwrite=true)`), garde non-vide.
* Gate durée **robuste** : probe ≤ 0 (ffprobe absent/dégradé) → pas d'échec (un
  fichier produit n'est pas rejeté faute de mesure).

== Décisions

* **Capture-once total** (pas par langue) : le deck US-1a est **monolingue** ; tous
  les variants partagent la même source → une capture suffit. La localisation par
  variante reste une US future (traduction / CAP-29) — le seam `capture` prendra
  alors la langue.
* **Seams capture/replicate** plutôt qu'une interface per-entry : rend la capture
  unique **explicite** dans le type et **testable**.
* **Gate durée robuste** : ne pas échouer un fichier produit quand ffprobe ne
  peut pas mesurer (mode dégradé).
