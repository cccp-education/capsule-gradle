== Mission

Deux dettes N1 non soldées côté capsule :

1. `VK-SPEAKER-NOTES US-1b` — la grammaire `[NOTE.speaker]` est au noyau depuis
   `0.9.0`, mais `RevealJsSpeakerNoteParser` en gardait une copie. Le statut
   « bloqué publication / reset Central » était **périmé** : `video-kernel 0.9.2`
   est servi par JitPack (canal par défaut).
2. `HF-MUSIC-LIBRARY` dette N2 — `capsule.audio.music.MusicLibrary` était une
   copie verbatim de `video.kernel.music`.

== Ce qui a été fait

* `gradle/libs.versions.toml` : `video-kernel 0.7.0 → 0.9.2`.
* `capsule/adapter/revealjs/RevealJsSpeakerNoteParser.kt` : **délègue** à
  `video.kernel.notes.SpeakerNoteBlockParser` (`headingLevel = 2`) ; ne reste que
  le mapping `SpeakerNoteBlock → VideoSegment` (index `1..n`, titre, narration).
  Parité legacy vérifiée par lecture : niveau 2 uniquement, note non fermée
  émise en fin d'entrée, note blanche ignorée, **première note gagne**.
* `capsule/audio/music/MusicLibrary.kt` **supprimé** ; les cinq types
  (`MusicLicence`, `MusicTrack`, `MusicLibrary`, `MusicSelection`,
  `MusicTrackSelector`) viennent de `video.kernel.music.*`. Le **loader Jackson**
  et `MusicAssetResolver` (plan de copie `sha256`, chemins) restent N2 — ce sont
  des adaptateurs, pas des contrats.
* Aucun test de domaine modifié (seuls des imports ajoutés) : le comportement est
  strictement inchangé.
