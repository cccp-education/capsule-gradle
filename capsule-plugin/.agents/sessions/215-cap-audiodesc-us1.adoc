== Livré

Domaine pur `capsule.a11y` (`src/main/kotlin/capsule/a11y/AudioDescriptionPlanner.kt`) :

* `NarrationWindow(startSeconds, endSeconds)` — fenêtre de narration, invariants
  `start >= 0`, `end > start`.
* `AudioDescriptionCue(text, durationSeconds)` — description authorée + durée
  parlée **estimée** (le planner est pur : pas de TTS, pas de mesure).
* `AudioDescriptionSegment(text, startSeconds, endSeconds)` — segment placé.
* `AudioDescriptionScript(segments, unplaced)` — plan ; `unplaced` **déclare la
  limite** quand les silences sont insuffisants (rien n'est silencieusement
  jeté, rien n'est écrasé sur la narration).
* `AudioDescriptionPlanner.plan(cues, narration, minGapSeconds, totalDurationSeconds)` :
  - narration triée + fenêtres chevauchantes fusionnées ;
  - silences = complément sur `[0, dernière narration]` (+ silence de fin si
    `totalDurationSeconds` fourni) ;
  - placement **first-fit** dans l'ordre des cues → déterministe ;
  - un segment est **toujours** disjoint de la narration ;
  - seuil `minGapSeconds` (défaut `0.5 s`) : un silence trop court est inutilisable.

'''
