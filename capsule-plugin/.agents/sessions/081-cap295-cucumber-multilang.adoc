== Objectif

Implémenter CAP-29.5 : le Cucumber BDD E2E multi-langue
(`multi_language_capsule.feature`) — deck source → 10 decks traduits →
10 scripts → 10 WebM, ttsLanguage adapté par langue, output naming
`<deckName>_<lang>.webm`, RTL ar/ur générés. Tags `@multilang @i18n`.
Engines NoOp (pas de vrais Piper/Playwright/ffmpeg).

== Méthode

Baby-step BDD strict : feature Gherkin → step defs → exécution cucumber
(`-PrunCucumber` — CR-10). Non-régression stricte : `./gradlew check`
(unit + functional + kover) VERT.

== Décisions d'architecture

. *Plan pur via `CapsuleVideoPlanner` dans les step defs* — les scénarios
  non-Gradle utilisent l'object pur `capsule.multilang.CapsuleVideoPlanner.plan()`
  directement (pas de GradleRunner) : vérification du plan 10 langues,
  convention de nommage, skip des langues sans paire, fail-fast plan vide.
. *E2E via GradleRunner NoOp* — les 2 scénarios GradleRunner appliquent le
  plugin + `ttsEngine = "noop"` + `captureEnabled = false` + deck source +
  scripts par langue, puis lancent `generateCapsuleVideoAllLanguages`.
  Assertions sur le log `CAPSULE MULTILANG → n/n languages rendered` +
  existence des WebM dans `build/capsules/`.
. *Nom de step distinct* — `Given a Gradle project with the capsule plugin
  applied and NoOp engines` (distinct du step existant sans NoOp → pas de
  DuplicateStepDefinitionException).

== Livrables

Tests (2 fichiers créés) :
. `src/test/features/multi_language_capsule.feature` — 6 scénarios `@multilang @i18n` :
  1. le plan génère 10 langues (LanguageCatalog complet, `demo_<lang>.webm`)
  2. la convention de nommage produit `<deckName>_<lang>.webm`
  3. une langue sans paire deck+script est skipée du plan
  4. le plan échoue si aucune langue n'a de paire (fail-fast)
  5. E2E GradleRunner NoOp → 10 WebM + log `CAPSULE MULTILANG → 10/10`
  6. E2E RTL ar/ur → WebM `demo_ar.webm` + `demo_ur.webm` générés
. `src/test/kotlin/capsule/scenarios/MultiLanguageCapsuleSteps.kt` — step defs :
  helpers `CapsuleVideoPlanner.plan()` purs (Given/When/Then) + 2 scénarios
  GradleRunner (NoOp engines, écriture deck source + scripts par langue dans
  les répertoires conventions, assertion log + fichiers `build/capsules/`).
