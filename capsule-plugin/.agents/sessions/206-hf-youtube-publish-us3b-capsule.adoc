== Décision d'architecture — option (a) duplication verbatim N2

Le pipeline OAuth/HTTP (`video.kernel.publish.VideoPublisher` = **port N1**,
implémentation = **N2**). La doctrine de factorisation autorise explicitement
**la duplication verbatim N2 d'une implémentation de port N1**
(`AGENTS.adoc` : « port en N0/N1 + implémentations N2 (duplication verbatim
tolérée) »). L'alternative (b) — module partagé N1 `youtube-publish` — reste
recommandée à terme (flux OAuth sensible) et est **tracée** ici comme EPIC
futur `PUBLISH-ADAPTER-N1` (hors périmètre).
