=== Fix Cucumber Consolidated (5 scénarios) ✅

Cause racine des 5 échecs `consolidated_capsule_model.feature` (préexistant depuis CAP-MODEL S-069, jamais GREEN car cucumber hangait) :

1. **`DuplicateStepDefinitionException`** : steps `the segment {int} should have title` et `should have speakerNote` définis en double dans `CapsuleSpeakerNotesSteps` ET `ConsolidatedCapsuleModelSteps` → glue de la classe consolidated ne chargeait pas → `UndefinedStepException` sur tous ses steps.
   - Fix : renommés en `the read segment ... should have title/speakerNote` dans `ConsolidatedCapsuleModelSteps` (sémantique distincte — lit `readScript` round-trip, pas `script`).

2. **Steps `{string}` non matchés** : feature écrivait `type HTML`/`type MANIM`/`manimScene null` sans guillemets, mais le pattern `{string}` exige des guillemets.
   - Fix : valeurs quotées dans le feature (`type "HTML"`, `type "MANIM"`, `manimScene "null"`).

3. **Bug `File.createTempFile`** : suffixe aléatoire → deck name `mydeck-script14686510855708924264` au lieu de `mydeck-script`.
   - Fix : création du fichier au nom exact dans un dossier temporaire (`File(dir, fileName)`).

Résultat : 64 cucumber tests, 0 FAIL (5 SKIP préexistants).
