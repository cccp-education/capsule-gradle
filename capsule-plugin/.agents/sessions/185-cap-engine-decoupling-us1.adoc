== Objectif

Livrer **US-1** de l'EPIC `CAP-ENGINE-DECOUPLING` : introduire le **modèle neutre**
engine-agnostique (`VideoSegment` / `VideoScript` / `VideoProductionEntry`) dans le
package `capsule.kernel`, avec **alias additifs** de compatibilité, sans casser le
plugin mature (0.0.10, CI verte).

== Méthode

Baby-step DDD/TDD/BDD strict (unit → fonctionnel → cucumber), **Local = Build /
Tests = CI** : seuls `compile*` / `assemble` / `validatePlugins` exécutés localement ;
les tests sont prouvés par la CI du push. **Zéro Python**, **English only**.

== Ligne rouge respectée — `capsule.kernel`

Le noyau ne parle **que** `segment` / `visual` / `kind` / `scene` / `engine` :
aucun `slide`, `deck`, `reveal`, `Playwright`. Le vocabulaire de rendu reste dans
les packages de compatibilité (`capsule.feed`, `capsule.multilang`).

=== Alias additifs de compatibilité

* `capsule.feed` : `typealias SlideSegment = VideoSegment`,
  `typealias CapsuleScript = VideoScript`, mappings `SlideType.toVideoKind()` /
  `VideoKind.toSlideType()`, accesseurs legacy `VideoSegment.type`,
  `VideoScript.deckName`.
* `capsule.multilang` : `typealias CapsuleVideoEntry = VideoProductionEntry`,
  `typealias CapsuleVideoPlan = VideoProductionPlan`, accesseur legacy
  `VideoProductionEntry.deckFile`.
* Accesseurs legacy membres `VideoSegment.speakerNote` / `.manimScene`
  (`@Deprecated`, `ReplaceWith`).

=== Migration interne (sites de construction)

* Les *lectures* restent couvertes par les accesseurs de compatibilité (zéro
  changement sémantique).
* Les *constructions* migrent vers le vocabulaire neutre : `speakerNote =` →
  `narration =`, `type = SlideType.X` → `kind = VideoKind.Y`, `manimScene =` →
  `scene =`, `CapsuleScript(deckName =)` → `name =`,
  `CapsuleVideoEntry(deckFile =)` → `visual = FileVisualSource(...)`.
* **Décision d'implémentation** : `SlideType` (HTML/MANIM) est **conservé** car il
  reste la **vocabulaire de sérialisation** du storyboard viral
  (`capsule.viral.StoryboardBeat`) et des marqueurs `-script.txt`
  (`[manim:Scene]`). Le mapping `SlideType ↔ VideoKind` fait le pont — éviter un
  renommage massif des features BDD et du format AsciiDoc storyboard.
* Imports d'extension legacy (`capsule.feed.type`, `capsule.feed.deckName`,
  `capsule.multilang.deckFile`) ajoutés aux appelants ; imports `SlideType`
  devenus inutiles supprimés (ktlint `no-unused-imports`).
