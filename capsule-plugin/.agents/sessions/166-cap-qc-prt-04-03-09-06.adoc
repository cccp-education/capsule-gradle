== Livrables — EPIC CAP-QC (4 items)

=== PRT-04 — Intégrité vidéo par décodage

Un clip abîmé garde une durée valide (MOOV dupliqué) et casse la concaténation ; le seul
contrôle qui l'attrape est de **décoder**.

* **Pur** : `capsule.validation.VideoIntegrityChecker` (`IntegrityResult` sealed
  `Clean`/`Corrupt` ; `verdict(exitCode, stderr)` — propre **seulement** si exit 0 **et**
  stderr vide) + `VideoIntegrityProbe` (`ffmpeg -v error -i <file> -f null -` ; fichier
  absent/vide = `Corrupt` sans lancer ffmpeg).
* **Câblage** : `validateCapsuleVideoDuration` gagne un gate intégrité opt-in
  (`validation.integrityEnabled`, défaut false) en plus de la durée ; `GradleException`
  actionable. Config 4 sources (DSL/CLI `-Pcapsule.validation.integrityEnabled`/ENV/
  gradle.properties) + push extension.
* **Tests** : `VideoIntegrityCheckerTest` (6 unit) + `VideoIntegrityProbeTest` (4 unit,
  seam `ProcessRunner.commandInterceptor`) + `capsule_video_integrity.feature` (3
  scénarios `@validation @integrity`, runner dédié 29e `cucumberTestVideoIntegrity`) + 3
  fonctionnels (`ValidateCapsuleVideoDurationFunctionalTest`).

=== PRT-03 — Sous-titres par beat (cartons)

Les sous-titres viennent du **texte source**, découpés en cartons lisibles, avec un
timing réparti au prorata de la longueur.

* **Pur** : `SubtitleTextNormalizer` (`spokenToDisplay` — strip markdown `**`, recollage
  des sigles épelés `A P I`→`API` ; `reversals` prêt pour PRT-01) +
  `SubtitleCartoner` (`split(text, maxChars=42)` — mots + fin de phrase, jamais un mot
  coupé) + `SubtitleTimingDistributor` (`distribute(cartons, start, duration)` — ranges
  contigus) + `SubtitleTimingCalculator.calculateFromCartons(...)` (un cue par carton,
  indices séquentiels ; `calculate` conservé).
* **Câblage** : `CapsuleVideoTask.generateSubtitles` branche sur
  `capture.subtitleCartonsEnabled` (défaut false) + `capture.subtitleMaxChars=42` ;
  config 4 sources + push.
* **Tests** : `SubtitleCartonsTest` (~20 unit) + `capsule_subtitles_cartons.feature` (4
  scénarios `@subtitle @cartons`, runner dédié 30e `cucumberTestSubtitlesCartons`) +
  test merger.

=== PRT-09 — Loudness 2 passes mesurée + limiteur

* **Pur** : `audio.LoudnormMeasurement` + `LoudnormAnalysisParser` (parse le bloc JSON
  `loudnorm` de la sortie fusionnée, sans Jackson) + `AudioPostCommand.loudnormMeasureArgs`
  (passe 1, `-f null -`), `buildTwoPassLoudnorm` (loudnorm `linear` + `measured_*` +
  `volume` + `alimiter limit=0.63:level=disabled` + `aresample=48000`) et
  `buildTwoPassArgv`.
* **Câblage** : `AudioPostProcessorImpl` chemin 2 passes **opt-in**
  (`audioPost.twoPassLoudnessEnabled`, défaut false), **single-input only** (no BGM) ;
  dégradation `false` si mesure illisible/ffmpeg en échec. Config 4 sources + push.
* **Tests** : `LoudnormAnalysisParserTest` (4 unit) + `AudioPostCommandTwoPassTest` (4
  unit) + `AudioPostConfigTest` étendu + `capsule_audio_post.feature` étendu (2 scénarios
  `@audio @post`, steps `CapsuleAudioLoudnessSteps`) + 1 fonctionnel.

=== PRT-06 — Signature de rendu (économie d'encre par contenu)

* **Pur** : `RenderSignature.of(engine, content, timeline)` → SHA-256 hex tronqué (16).
* **Câblage** : `CapsuleVideoTask` écrit un sidecar `<video>.sig` après une capture ; la
  **réutilisation** est opt-in (`capture.reuseCapturedVideoEnabled`, défaut false) et
  n'a lieu que si la signature correspond **ET** que la vidéo décode (PRT-04). Config 4
  sources + push.
* **Tests** : `RenderSignatureTest` (5 unit) + `capsule_render_signature.feature` (3
  scénarios `@capture @signature`, runner dédié 31e `cucumberTestRenderSignature`) +
  `RenderSignatureFunctionalTest` (sidecar écrit + stable) + test merger.

== Leçon

Le portage « technique pure + câblage opt-in (défaut false) + tests » permet d'absorber
quatre items d'un dépôt externe en une session sans changer le comportement par défaut
(zéro régression) — la CI est la seule preuve, la compilation locale le seul garde-fou.
