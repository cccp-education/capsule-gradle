=== Migration corrective (découverte en US-1/US-2)

`RemotionCapture.kt` et `RemotionTemplate.kt` utilisaient encore
`ProcessBuilder` direct (non migrés par PR #2) — contredisant l'audit.
Corrigé dans US-1 : `RemotionCapture.isAvailable()` →
`ProcessRunner.probe(...)`, `capture()` → `ProcessRunner.run(...)` ;
`RemotionTemplate.ensureDependencies()` → `ProcessRunner.run("npm","install",...)`.
Ajout des seams de test `ProcessRunner.commandInterceptor` (refactor `run`→
`realRun`) et `FileReplace.moveOverInterceptor`.
