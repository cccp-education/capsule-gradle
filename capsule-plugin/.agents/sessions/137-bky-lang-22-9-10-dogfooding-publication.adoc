== Bug P0 découvert par le dogfooding réel — chaîne script cassée

La S-082 (dogfooding 3 langues) avait contourné par un `mv` manuel, jamais
corrigé dans le code. La chaîne réelle est cassée par construction :

- `translateDeck` (slider) produit `<slug>_<lang>-deck.adoc`.
- `extractSpeakerNotes` dérive le script du nom de fichier `.adoc` sans
  extension → `<slug>_<lang>-deck-script.txt` (le suffixe `-deck` survit).
- `CapsuleVideoPlanner` cherchait exactement `<deckName>_<lang>-script.txt`
  → **aucune paire trouvée** → fail-fast `no matching deck + script pair`.

Les tests (NoOp, `demo_<lang>` hand-nommés) ne reproduisaient jamais la
divergence header/nom de fichier — d'où l'invisibilité.
