== Constats du dogfooding

. ✅ **Gate éditorial CAP-CONTEXT actif** : un storyboard portant un fil conducteur
  narratif **sans** transitions par beat est correctement rejeté (règle tout-ou-rien
  + transition par séquence). Le garde-fou fonctionne ; le storyboard a été complété.
. ⚠️ **Erreur LLM transitoire** (`too many concurrent requests`) → la tâche
  `generateViralCampaign` **échoue** (pas de dégradation). *Convention projet* :
  aucun adaptateur LLM (`ChatModelViralHookGenerator`, `ChatModelTranscriptEnhancer`,
  `ChatModelCapsuleLlm`) ne catch les erreurs de transport — seul un retour **blanc**
  dégrade. Comportement **cohérent** avec l'existant ; une **résilience LLM
  transverse** (transport → repli sur le message du storyboard) est un **candidat
  EPIC** (hors scope US-4). Retry manuel → run vert.
. ⚠️ **Manim absent** localement : le « chemin enrichi Remotion+Manim » n'a pas été
  exercé. Note : la voie **virale force le socle FFmpeg** (`ViralCaptureStrategy`
  → `SCREENSHOT`), l'enrichissement Remotion+Manim relevant du pipeline général
  (US-7). Dogfooding Remotion+Manim = candidat distinct (nécessite `manim`).
