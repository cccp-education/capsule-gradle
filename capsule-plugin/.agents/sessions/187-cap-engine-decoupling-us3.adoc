=== Adapter `capsule.adapter.revealjs` (créé)

[cols="1,3", options="header"]
|===
| Fichier | Rôle
| `RevealJsSpeakerNoteParser.kt` | **Pur** : parse un deck AsciiDoc (`== Title` + bloc `[NOTE.speaker]`) → `VideoScript` (segments réindexés 1..n, slides sans note ignorées).
| `RevealJsScriptContract.kt` | **Pur** : contrat `-script.txt` — `write(VideoScript): String` (marqueurs `[manim:Scene]`/`[html]`) + `read(File): VideoScript` (round-trip idempotent).
| `RevealJsSpeakerNoteSource.kt` | Implémente `SegmentSource` : `segments(File)` délègue au parser (nom de fichier → `name`).
|===

* `capsule.feed.CapsuleScriptReader.read` → `RevealJsScriptContract.read`.
