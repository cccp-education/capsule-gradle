== Décisions d'architecture

. *Consommer `LanguageCatalog` (10 langues) au lieu d'étendre l'enum local à 10* — évite la dette technique d'un enum détruit dans CAP-ARCH-1. Pattern : document-gradle (`DocumentI18nBridge`), plantuml-gradle (`PlantumlTranslationServiceAdapter`).
. *Nouveau domaine DDD `capsule.multilang`* (7ème après `capsule.feed`, `capsule.capture`, `capsule.tts`, `capsule.subtitles`, `capsule.manim`, `capsule.config`). `VoiceMapping` migré de `capsule` vers `capsule.multilang`, keyé par code String (pas par enum).
. *`MultiLanguageResolver`* : object pur, pont entre `LanguageCatalog` (N0) et `VoiceMapping` (Piper/espeak). `resolve(code): ResolvedLanguage?` (data class immutable : `SupportedLanguage` + `piperModel` + `espeakVoice`).
. *`Language` enum supprimé* — `Language.fromCode()` remplacé par `MultiLanguageResolver.resolve()` dans `CapsuleVideoTask.kt:197` et `CapsuleBuildTask.kt:40`. `TtsEngine.language()` retourne `SupportedLanguage?` (was `Language?`).
