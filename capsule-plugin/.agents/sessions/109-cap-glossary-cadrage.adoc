. **12 décisions architecturales** :
  1. *Glossaire = extension capsule-local* (pattern `scenarioSection`
     CAP-SPD-2), pas 6ème canal N0. `CapsuleContext` 4ème champ
     `glossarySection: String = ""`. Invariant ajusté `rendered.isBlank()
     == (channels.isEmpty() && scenarioSection.isBlank() &&
     glossarySection.isBlank())`. Pas de bump codebase-contracts (le sealed
     `ContextChannel` N0 reste intact — 5 variants Eager/Rag/Graphify/
     Resource/Docs). Pattern CAP-SPD-2 mirror.
  2. *`GlossaryEntry(term: String, definition: String)`* data class
     immutable (invariant fail-fast si `term` ou `definition` blank).
  3. *`GlossaryContext(terms: List<GlossaryEntry>)`* data class immutable
     (liste ordonnée, pas map — l'ordre des termes a une valeur pédagogique,
     le premier terme est le plus important).
  4. *`GlossaryLoader`* object pur (mirror `PedagogicalScenarioLoader`) —
     `load(glossaryFile: File, maxTokens: Int): String`. Parse AsciiDoc
     `== Glossary` section + bullets `- term: definition`, rend `====
     Official Glossary (glossary)\n<term>: <definition>\n...`, tronque via
     `ContextChannel.Docs.truncateToTokens(maxTokens)` (réutilise le variant
     Docs, pattern `PedagogicalScenarioLoader` L67).
  5. *Format glossaire = AsciiDoc* (format natif du workspace, pas de
     nouvelle dépendance parsing). Parsing purement textuel, pattern
     `PedagogicalScenarioLoader.extractBulletSection`. Format alternatif
     (futur) : CSV/JSON si besoin — l'API `GlossaryLoader.load(file,
     maxTokens)` est format-agnostic, US-1 implémente uniquement `.adoc`
     (MVP0 — workspace AsciiDoc-native).
  6. *Budget glossaire* : 5% du total (8000 × 0.05 = 400 tokens), pattern
     `scenarioSection` (`CollectCapsuleAugmentedContextTask.
     resolveScenarioSection` L282). Un glossaire AFNOR/REAC typique = 30-50
     termes × 10-20 tokens/définition = 300-1000 tokens. 400 tokens budget
     = ~30 termes retenus (troncation aux plus importants, ordre préservé).

     budget=8000, scenarioSection="", glossarySection="", tracker=null)`.
