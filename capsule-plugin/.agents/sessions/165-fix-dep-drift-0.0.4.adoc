== Constat (S-164)

Le POM `capsule-plugin 0.0.3` importait **`workspace-bom:0.0.43`** : le catalogue
**interne** du plugin épinglait une BOM très ancienne (`workspace-bom = "0.0.43"`,
`codebase = "0.0.14"`, `slider = "0.0.18"`, `koog = "1.0.0"`, `jackson = "2.18.3"`) —
identique à la release 0.0.2 (S-151). Dérive de maintenance.

== Correctif (S-165)

Alignement du catalogue interne du plugin sur la BOM courante (valeurs du catalogue
workspace MEMPHIS 0.0.79) :

* `workspace-bom` `0.0.43` → **`0.0.79`** ;
* `codebase` + `codebase-gradle-plugin` `0.0.14` → **`0.0.17`** ;
* `slider` `0.0.18` → **`0.0.19`** ; `koog` `1.0.0` → **`1.3.0`** ;
  `jackson` `2.18.3` → **`2.21.2`** ; `langchain4j` (sans pin → BOM) → **1.22.0**.
* Bump version plugin `0.0.3` → **`0.0.4`**.

*Note* : l'import BOM `platform(...)` imposant la version **la plus haute**, les
dépendances effectives étaient déjà celles de 0.0.79 ; aligner les pins explicites
les rend **cohérents** (pas de risque additionnel).
