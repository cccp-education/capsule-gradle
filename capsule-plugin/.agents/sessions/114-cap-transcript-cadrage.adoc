. **12 décisions architecturales** :
  . **Domaine `capsule.transcript` 11ème** — nouveau domaine DDD pur (data
    classes immutable + object pur builder + port/adapter LLM), pattern
    `capsule.audio`/`capsule.validation`/`capsule.context`. Fichiers prod
    dans `src/main/kotlin/capsule/transcript/`.
  . **`TranscriptConfig` 11ème section `CapsuleConfig`** — 2 champs
    `enabled: Boolean = false` (défaut backward compat — transcript opt-in)
    + `strategy: TranscriptStrategy = TranscriptStrategy.TEMPLATE` (défaut
    safe, pas de LLM requis). Pattern `ValidationConfig` (2 champs, defaults
    backward compat).
  . **`TranscriptStrategy` enum type-safe 2 valeurs** — `TEMPLATE` (assemble
    AsciiDoc depuis segments, zéro LLM, déterministe) + `LLM` (enrichit via
    `TranscriptLlmEnhancer`, requiert `LlmBuildService`). Défaut `TEMPLATE`
    (backward compat + économie d'encre + pas de dépendance LLM pour usage
    basique). Companion `fromString` case-insensitive fallback `TEMPLATE`
    (pattern `OutputFormat`/`CaptureStrategy`).
  . **`TranscriptPlan` data class immutable** — `deckName: String`,
    `segments: List<SlideSegment>` (consomme `capsule.feed.SlideSegment` —
    pas de nouveau modèle, réutilise l'existant), `language: String`,
    `outputPath: String`. Invariants `deckName.isNotBlank()` +
    `language.isNotBlank()` + `outputPath.isNotBlank()`. Pattern
    `CapsuleVideoPlan` (CAP-29.2 `capsule.multilang`).
  . **`TranscriptBuilder` object pur** — `build(plan): String` assemble
    template AsciiDoc : `= <deckName>` (titre level 0) + `:language: <lang>`
    (attribute) + intro boilerplate + une section `== <title>` par segment
    avec `speakerNote` body + outro boilerplate. Zéro I/O, zéro LLM, fully
    testable. Pattern `CapsuleScriptWriter` (object pur `write(script):
    String`).
  . **`TranscriptLlmEnhancer` port + adapter** — port `fun enhance(template:
    String, plan: TranscriptPlan): String` (sync, pattern `CapsuleLlm.
    propose/generate`). Adapter `ChatModelTranscriptEnhancer` bridge
    `ChatModel` langchain4j (pattern `ChatModelCapsuleLlm`). Enrichit :
    transitions entre sections, introductions engageantes, reformulations
    pédagogiques, garde le structure AsciiDoc (`== ` headings préservés).
    Fallback : si LLM retourne blank/invalide → template original (degraded,
    pattern `AudioPostProcessor.process` retourne Boolean).
  . **`TranscriptPromptBuilder` object pur** — `buildEnhancePrompt(plan):
    String` prompt pédagogique (pattern `DefaultCapsulePromptBuilder`).
    Instructions : "enrich the AsciiDoc article with pedagogical transitions,
    keep `== ` headings, keep speaker notes content, add introductory and
    concluding paragraphs, respond with AsciiDoc only".
  . **Tâche `generateCapsuleTranscript`** — groupe `generate` (réutilise
    `task.group.generate`), `@OutputFile transcriptOutput` =
    `build/capsule/<deckName>-transcript.adoc`. Inputs : `@InputFile
    speakerNotesFile` (dépend `generateCapsuleContent` output) + `@Input
    language` + `@Input strategy` + `@Optional @ServiceReference
    LlmBuildService` (si strategy=LLM). Économie d'encre : skip si
    `transcriptOutput` existe ET non-blank. `dependsOn
    GENERATE_CAPSULE_CONTENT`. Wiring
    `CapsuleManager.registerGenerateTranscriptTask`.
  . **4 sources DSL** — `transcriptEnabled` + `transcriptStrategy` 4 sources
    (ENV `CAPSULE_TRANSCRIPT_ENABLED`/`CAPSULE_TRANSCRIPT_STRATEGY` < props
    `capsule.transcript.enabled`/`capsule.transcript.strategy` < YAML < CLI
    `-Pcapsule.transcript.enabled`/`-Pcapsule.transcript.strategy`).
    `mergeTranscriptConfig` pattern `mergeValidationConfig` (`mergeBoolean` +
    `mergeStr` pour strategy → `TranscriptStrategy.fromString`).
    `CapsuleExtension` 2 properties + `CapsuleConventions` 2 champs +
    `pushConfigIntoExtension` transcript block (Variant B).
  . **Pas de nouvelle factory `resolve*`** — `TranscriptBuilder` est object
    pur (pas d'I/O, pas de ffmpeg, pas de Playwright).
    `TranscriptLlmEnhancer` adapter construit in-task depuis `resolveModel`
    (pattern `GenerateCapsuleContentTask` L88-93 — `project.aiProvider` +
    `project.resolveModel(provider, llmService)` +
    `ChatModelTranscriptEnhancer(model)`). Zéro factory `resolve*`
    supplémentaire.
  . **Runner dédié `CapsuleTranscriptCucumberRunner`** (pattern S-082) +
    `CapsuleTranscriptSteps` préfixés "transcript" (bug S-088 glue
    `capsule.scenarios` partagée) + `CucumberTaskSpec("cucumberTestTranscript")`
    15ème câblé `build.gradle.kts` (après `cucumberTestGlossaryContext` L153,
    avant `cucumberTestIntegration` L159). Tags `@transcript`.
  . **`CapsuleMessages` clé `task.generateCapsuleTranscript.description`** —

    `task.group.generate` réutilisé (transcript = génération contenu, pas
