  (contrat `*-script.txt` de `capsule.feed`).

  pattern `codebase.KoogAugmentedContextGraph` : `execute()` séquentiel,

== Dogfooding réel (validé en clôture S-086)

Exécuté depuis la **racine consommateur** `capsule-gradle/` (pattern
"Racine Consommateur", article 0124 — zéro `includeBuild`, zéro consumer

     `education.cccp.capsule` (renommage groupId), slider `0.0.14` →
     `0.0.16`.

     `capsule-plugin:0.0.1-SNAPSHOT` — le BOM `workspace-bom:0.0.16`

     rétablit le SNAPSHOT.
