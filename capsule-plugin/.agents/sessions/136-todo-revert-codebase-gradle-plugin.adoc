== Contexte hérité

Borough Détroit : tous EPICs terminés (DORMANT). Seul point d'attention
restant au BACKLOG = **TODO REVERT** : `codebase-gradle-plugin` épinglé
`0.0.10` comme workaround d'un bug amont Gradle 9.7.1 — `CodebaseOcrExtension`
(codebase) déclarait `abstract val ocrEngine: Provider<OcrEngine>`, et Gradle
ne sait décorer des propriétés abstraites que de type `Property`/`ListProperty`
— jamais un `Provider` nu. Application échouait sur « Cannot have abstract
method CodebaseOcrExtension.getOcrEngine(): Provider<OcrEngine> ».

Le correctif amont `fb19b7c` (suppression de la propriété morte) a été publié
dans codebase-gradle ≥ 0.0.11 ; la lib `codebase-plugin` est maintenant à
0.0.14 (bump pub S-214, bundle `3e82490d`).
