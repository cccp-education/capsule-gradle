== Objectif

CAP-ARCH-5 — i18n aligné sur le socle : créer l'infrastructure `CapsuleMessages`
(pattern `SliderMessages`/`PlantumlMessages`), traduire les task descriptions
en 10 langues, fixer les 3 descriptions françaises hardcoded dans
`CapsuleManager.kt` (violation règle English-only).

== Audit préalable

Audit complet i18n capsule (sous-agent explore) :

* *Déjà i18n'd* : pipeline multi-langue CAP-29 (`MultiLanguageResolver` →
  `LanguageCatalog` 10 langues, `VoiceMapping`, `generateCapsuleVideoAllLanguages`).
* *Gaps* : (1) zéro `Messages*.properties` (contrairement à slider 11 fichiers
  + plantuml 11 fichiers), (2) 3 descriptions de tâches en français dans
  `CapsuleManager.kt` (lignes 69, 89, 97), (3) ~80 messages log hardcoded
  English littéraux.

Audit socle i18n (sous-agent explore) :

* `i18n-contracts` N0 : `LanguageCatalog`/`SupportedLanguage` (consommés),
  `TranslationService` (consommé par slider/document), `MessageBundle`/
  `LocaleResolver` (contrats morts, zéro consommateur).
* `DocumentI18nBridge` (document-gradle) = *supprimé* S-030 (code mort,
  anti-pattern). Ne pas recréer de "Bridge".
* Pattern prouvé : `SliderMessages`/`PlantumlMessages` object + 11
  `Messages*.properties` (ResourceBundle UTF-8 custom Control +
  `MessageFormat`). Duplication cross-borough acceptée (futur EPIC extraction).

== Décisions

* *Pas de `CapsuleI18nBridge`* : anti-pattern `DocumentI18nBridge` supprimé
  S-030 (code mort). Pattern prouvé = `XxxMessages` object direct.
* *Pas de `MessageBundle`/`LocaleResolver`* : contrats N0 morts (zéro
  consommateur cross-borough). `ResourceBundle.Control` UTF-8 custom est le
  pattern prouvé (slider/plantuml).
* *`Messages_en.properties` explicite* : requis car `Locale.ENGLISH` sans
  fichier `_en` explicite fallback sur default locale système (`fr_FR`).
  Pattern slider/plantuml.
* *`task.group.capsule` non traduit* : "capsule" est un nom propre (plugin
  name), identique dans toutes les langues. Exclu du test `assertNotEquals`.
