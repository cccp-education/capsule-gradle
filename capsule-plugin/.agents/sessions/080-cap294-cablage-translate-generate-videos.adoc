== Objectif

Implémenter CAP-29.4 : la tâche composite `translateAndGenerateCapsuleVideos`
qui câble le pipeline complet multi-langue : deck source →
`translateAndExtractSpeakerNotes` (slider `translateDeck` → capsule
`extractSpeakerNotes`) → `generateCapsuleVideoAllLanguages` (10 WebM).
Dépendances : `translateAndExtractSpeakerNotes` + `generateCapsuleVideoAllLanguages`.

== Méthode

Baby-step TDD strict : RED → GREEN, 1 niveau de test (functional — pas d'unit
possible pour un câblage Gradle pur, pas de cucumber avant CAP-29.5). Non-régression
stricte : la tâche est purement déclarative (dependsOn), aucune logique métier.

== Décisions d'architecture

. *Nom de tâche dans le domaine* — `CapsuleFeedTaskNames.TRANSLATE_AND_GENERATE_CAPSULE_VIDEOS`
  + description `TRANSLATE_AND_GENERATE_VIDEOS_DESCRIPTION` ajoutés dans
  `capsule.feed.CapsuleFeedTaskDomain` (stable task identifiers — pattern existant).
. *Registration dans `CapsuleFeedTaskRegistrar`* — `registerTranslateAndGenerateCapsuleVideos(project)`
  : `tasks.register(name)` + `group = "capsule"` + description + `dependsOn`
  (`TRANSLATE_AND_EXTRACT_SPEAKER_NOTES` via constante + `"generateCapsuleVideoAllLanguages"`).
  Tâche composite sans classe (pure orchestration Gradle).
. *Câblage `CapsuleManager.registerExtractSpeakerNotesTask()`* — ajout du 3ème
  appel registrar (à côté de `register` + `registerTranslateAndExtractSpeakerNotes`).
  La tâche n'a pas de classe propre — Gradle l'expose en lifecycle task.
