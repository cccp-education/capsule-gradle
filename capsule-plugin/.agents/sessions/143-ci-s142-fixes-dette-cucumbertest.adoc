== 2. Dette `cucumberTest` (14 scénarios) — résolue

=== Diagnostic (sans test local)

Le runner global `cucumberTest` n'est invoqué par aucun workflow de push
(`Full Tests` ne lance que `test functionalTest` + runners dédiés) : la dette était
**latente**. Pour l'obtenir sans rendre le push rouge, un workflow **manuel**
`cucumber-full.yml` (`workflow_dispatch`) exécute `cucumberTest` et publie les
rapports. Run `37965407935` : **360 tests, 14 failed, 150 skipped**.

=== Cause racine (au code)

Les 14 échecs étaient des `initializationError` /
`org.junit.platform.suite.engine.NoTestsDiscoveredException` sur les **14 suites
`@Suite` dédiées** (pattern S-082) — **pas** des échecs de scénarios :

- la tâche globale `cucumberTest` (conventions) collecte **toutes** les classes
  `@Suite` de `capsule.scenarios`, donc aussi les 14 runners dédiés par feature ;
- leur `@SelectClasspathResource("features/<f>.feature")` **ne résout pas** sous la
  tâche globale : les `.feature` sont copiés à la **racine** du classpath de test
  (`build/resources/test/`), pas dans un sous-répertoire `features/` ;
- leurs tâches dédiées (`cucumberTest<Feature>`) passent car elles injectent
  `cucumber.features` (`CucumberTaskSpec.features`), ce qui court-circuite la
  sélection par ressource ;
- le runner agrégé `CucumberTestRunner` (`@ConfigurationParameter(FEATURES_PROPERTY_NAME=src/test/features)`)
  couvre **déjà toutes** les features : **153 scénarios PASSED, 0 FAILED**.

Le task global était donc **mal scopé** : il ramassait les runners dédiés qui ne
sont pas faits pour tourner dans ce contexte.

=== Fix

`build.gradle.kts` — scoper la tâche globale à son runner agrégé :

[source,kotlin]
----
tasks.named("cucumberTest", Test::class.java) {
    filter.includeTestsMatching("capsule.scenarios.CucumberTestRunner")
}
----

Les 23 runners dédiés gardent leurs tâches propres (déjà câblées en CI S-142).

=== Preuve

Workflow diagnostic `37967978808` (commit `741ecce`) : **BUILD SUCCESSFUL in
16m41s**, **0 `initializationError`**, `CucumberTestRunner` **153 PASSED**. Dette
close.
