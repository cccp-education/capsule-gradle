== Audit au code (constats)

* `TtsEngine` n'a **aucun** contrôle qualité ; `NoOpTtsEngine` écrit un **texte** sous
  extension audio ; **aucun ASR** dans `src/main` ; le karaoké viral trame les mots
  **proportionnellement**, sans alignement réel ; pas de normalisation pour **comparer**
  dit ↔ transcrit ; `synthesizeTtsForScript` ne retente qu'une fois, sans mesure ;
  `ExternalBinaryAssumption`/`BinaryAvailability` permettent de skipper un binaire absent.
* Source `prepa` : `verif_voix.py` (fidélité mot-à-mot + souffle), `score_voix.py` /
  `rapport_voix.py` (normalisation, recollage des sigles), `compare_prises.py` (choix de
  prise), `verif_voix_par.py` (sharding).

== Décision

* **Domaine pur** `capsule.voice` : `TextNormalizer`, `WordAligner`, `FidelityScorer`,
  `SnrEstimator`, `VoiceScore`.
* **Port** `SpeechRecognizer` (adapter CLI whisper, hors JVM, jamais dure) + **tâche**
  `verifyCapsuleVoice` (groupe `verification`, rapport JSON, seuils, strict).
* **Choix de prise** : régénérer + retenir la meilleure (fichier de sélection).
* **Opt-in** `voice.verifyEnabled` (défaut false) + seuils DSL ; `VoiceConfig` 4 sources.
* **Dégradation** : ASR absent → skip ; `strictMode` → échec ; la CI **ne dépend jamais**
  de l'ASR pour le vert (`assumeTrue`).
* **5 US ~14 pts** (US-0 ✅ cadrage ; US-1 domaine pur, US-2 port+tâche, US-3 choix de
  prise, US-4 BDD + dogfooding, US-5 karaoké optionnel).
