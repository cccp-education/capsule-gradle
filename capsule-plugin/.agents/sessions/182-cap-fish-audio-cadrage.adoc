== Mission

Demande pilote : **réintroduire dans `capsule` le support du moteur TTS cloud
Fish Audio**, comme dans l'usine `prepa_electricite_complet`. Le pilote dispose
d'une clé API dans `fish.yaml` (gitignoré) et demande un **mappage Jackson** pour
la configuration `fish-audio`. Session : cadrage (décisions + découpage) **puis**
implémentation US-1→US-3 et publication de la release `0.0.9`.
