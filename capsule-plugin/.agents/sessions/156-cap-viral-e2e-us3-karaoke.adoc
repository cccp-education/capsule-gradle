== Mission

Dernier US de l'EPIC CAP-VIRAL-E2E : clore le constat C3 du cadrage
(`KaraokeSubtitleBuilder` sans usage prod). Les sous-titres stylés mot-à-mot du
format court sont produits et référencés par le manifeste de campagne.

== Livrable

=== Domaine pur (unit)

* `capsule.viral.KaraokeLine` + `KaraokeWordPlanner` (objet pur) : `plan(beats)`
  → une ligne par beat, mots **timés proportionnellement à leur longueur** dans
  la fenêtre du beat (curseur cumulé, déterministe). Le texte parlé est le beat
  intent — jamais inventé.
* `capsule.viral.AssKaraokeDocument` (objet pur) : `build(lines)` → document ASS
  v4.00+ complet (`[Script Info]` portrait 1080×1920, un style `Viral`, un
  `Dialogue` par ligne) réutilisant `KaraokeSubtitleBuilder.buildKaraokeText` +
  `formatAssTimestamp`. `KaraokeSubtitleBuilder.fileNameFor` = `<id>.ass`.
* Tests : `KaraokeWordPlannerTest` (5) + `AssKaraokeDocumentTest` (5).

=== Câblage (functional)

* `CampaignBundle.subtitleFile` (champ **additif**, défaut `""`, `hasSubtitle`) +
  `CampaignBundleSerializer` (écriture + `parseManifest`) + `ViralCampaignGate`
  vérifie le `subtitleFile` non-blanc (comme le thumbnail) + `ViralCampaignAssembler`
  `subtitleFor`.
* `GenerateViralCampaignTask` : `subtitleFor` alimenté →
  `CampaignBundle.subtitleFile` pointe `<variant.id>.ass`.
* `RenderViralSubtitlesTask` (groupe `generate`, `dependsOn generateViralCampaign`) :
  lit le storyboard, planifie, écrit `<id>.ass` par variante (Économie d'Encre :
  skip si présent). **Pur texte** — zéro Chromium, zéro FFmpeg.
* `CapsuleManager` : `registerRenderViralSubtitlesTask` + `validateViralCampaign`
  `dependsOn renderViralVariants, renderViralThumbnails, renderViralSubtitles`
  (le gate vérifie désormais vidéo + thumbnail + soustitre).
* `RenderViralSubtitlesFunctionalTest` : 5 tests TestKit (registration, skip par
  défaut, écriture karaoké par variante, économie d'encre, storyboard manquant →
  warning).

=== BDD (cucumber)

* `capsule_viral_karaoke.feature` `@karaoke` : 4 scénarios (fenêtre de beat,
  découpage mot-à-mot, document ASS avec dialogue, beat mono-mot).
* `CapsuleKaraokeSteps` (préfixés « karaoke », S-088) +
  `CapsuleViralKaraokeCucumberRunner` (S-082).
* `CucumberTaskSpec("cucumberTestViralKaraoke")` câblé + `full-tests.yml`.

=== Tests US-1 étendus

`ViralCampaignGateTest` : +2 (subtitle manquant listé, subtitle blanc
non-violation) + round-trip incluant le subtitle.
