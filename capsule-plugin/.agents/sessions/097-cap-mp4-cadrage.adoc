== Décisions architecturales (10)

. *`OutputFormat` enum (pas string)* — type-safe, 3 valeurs `WEBM`/`MP4`/`BOTH`,
  défaut `WEBM` (backward compat — configs existantes sans `output.format`
  gardent le comportement WebM seul). Companion `fromString` case-insensitive,
  fallback `WEBM` pour null/blank/unknown. Pattern `CaptureStrategy` (S-096) /
  `VersioningStrategy` (S-087).

. *Section `output` étendue (pas de nouvelle section)* — `OutputConfig` (3
  champs) étendu avec 4ème champ `format: OutputFormat = OutputFormat.WEBM`.
  Pas de nouvelle section config. Pattern `CaptureConfig.strategy` (15ème
  champ ajouté en S-096).

. *`mergeOutputFormat` helper dédié (pattern `mergeVersioning`)* — le merger a
  déjà 2 helpers enum dédiés (`mergeVersioning`, `mergeCaptureStrategy`).
  `mergeOutputFormat` suit le même pattern : CLI > YAML > props, fallback
  `WEBM` pour null/blank. Pas de helper générique (3 enum ont chacun leur
  fallback distinct — `PLAYWRIGHT`/`TIMESTAMP`/`WEBM`).

. *4 sources pattern respecté* — ENV `CAPSULE_OUTPUT_FORMAT` < props
  `capsule.output.format` < YAML `output.format` < CLI
  `-Pcapsule.output.format`. `loadFromEnvironment` + `buildConfigFromProperties`
  étendus.

. *`VideoFormatConverter` (object pur, domaine `capsule`)* —
  `convertToMp4(webmFile, mp4File, ffmpegPath): Boolean` lance FFmpeg transcode
  `-c:v libx264 -c:a aac -movflags +faststart -y`. NoOp fallback (retourne
  `false`, log warn). `isAvailable(ffmpegPath): Boolean` (pattern
  `MediaProbeUtil.isFfprobeAvailable`). Factory `resolveFormatConverter`
  + `StrictModeGuard.requireAvailable` (ffmpeg absent → fail si strict, comme
  `resolveSubtitleBurnInService`).

. *Wiring `CapsuleVideoTask` post-burnIn* — étape `convertFormatIfEnabled(
  finalVideo)` après `burnInSubtitlesIfEnabled` dans `captureDeckSequential`
  (L492) + `captureDeckParallel` (L522). Si `output.format == MP4` : transcode
  + supprime le WebM final, garde `.mp4`. Si `BOTH` : transcode + garde WebM
  + `.mp4`. Si `WEBM` : no-op (backward compat). `CapsuleExtension.outputFormat:
  Property<OutputFormat>` + helper Groovy `outputFormat(String)`
  (case-insensitive, pattern `captureStrategy(String)`).

. *`DistributeCapsuleVideoTask` étendu* — filtre actuellement `*.webm` seul
  (L56). Étendu pour filtrer selon `output.format` : `.webm` si WEBM, `.mp4`
  si MP4, `.webm` + `.mp4` si BOTH. `task.format: Property<OutputFormat>`
  ajoutée, résolu depuis le merger. Économie d'encre préservée (skip si
  destination existe + non-vide, déjà implémenté S-087).

. *`CapsuleConventions.outputFormat` étendu* — convention `WEBM` ajoutée
  (pattern `captureStrategy`). `pushConfigIntoExtension` push format (guard
  convention, pattern `captureStrategy` avec `isPresent`).

. *Économie d'encre (AGENT.adoc)* — skip transcode MP4 si `.mp4` existe ET
  `MediaProbeUtil.probeDuration(mp4) > 0` (mp4 valide). Skip WebM→MP4 si
  format == WEBM (no-op). Skip distrib si fichier destination existe +
  non-vide (déjà implémenté S-087).

. *Cucumber runner dédié* `CapsuleFormatCucumberRunner` (pattern S-082
  `@SelectClasspathResource("features/capsule_format.feature")` + filter
  `@distrib and @format and not @wip and not @integration`). Steps
  `CapsuleFormatSteps` préfixés "format distribution" (bug S-088 glue
  `capsule.scenarios` partagée — step texts doivent être uniques).
  `CucumberTaskSpec("cucumberTestFormat")` câblé `build.gradle.kts`.
