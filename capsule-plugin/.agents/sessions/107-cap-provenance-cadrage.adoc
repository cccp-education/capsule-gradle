== Ce qui a été fait

. **Audit code** — 6 points audités :
  - `CapsuleContextBuilder.build(composite, budget, scenarioSection)` L60-75
    — pure object, les `channels` sont les `ContextChannel` N0 budgetés +
    filtrés, aucun tracking du nom de fichier source (le `composite.eagerSection`
    est déjà flatté en un seul string).
  - `CollectCapsuleAugmentedContextTask.run()` L98-132 — assemble le
    `composite`, écrit `augmented-context.txt`, aucun artefact de provenance.
    *Le task connaît les sources* (`eagerFiles.files`/`docsFiles.files`/
    `scenarioFile.files`/`ragContent`/`graphifyContent`) — lieu naturel du tracking.
  - `ContextChannel` N0 sealed 5 variants — aucun champ source file = bump
    codebase-contracts multi-borough si touché → **extension capsule-local**
    (pattern CAP-SPD-2 `scenarioSection`).
  - `ChannelBudget` N0 (8000 tokens, 0.40/0.30/0.20/0.10/0) — pas de per-source.
  - `ContextConfig` 2 champs, `CapsuleConfigMerger`/`CapsuleExtension`/
    `CapsuleConventions`/`pushConfigIntoExtension` pas de provenance.
  - Jackson déjà dépendance (`jacksonObjectMapper`/`ObjectMapper`/`YAMLFactory`),
    12 `CucumberTaskSpec` existants, runners de référence
    `CapsuleContextCucumberRunner` + `CapsuleScenarioContextCucumberRunner`.

. **11 décisions architecturales** :
  1. Pas de nouveau domaine — `ContextProvenance` + `ProvenanceSource` +
     `ProvenanceTracker` rejoignent `capsule.context` existant.
  2. `ProvenanceSource(fileName, chars, tokens)` data class immutable.
  3. `ProvenanceChannel(channel, sources)` + `totalChars()`/`totalTokens()`.
  4. `ContextProvenance(channels)` + `toJson()` Jackson INDENT_OUTPUT
     (schema `{ "channels": [...], "totalChars": N, "totalTokens": M }`).
  5. `ProvenanceTracker` mutable accumulator + `build()` snapshot immutable.
  6. `CapsuleContextBuilder.build()` étendu `tracker: ProvenanceTracker? = null`
     optional backward compat.
  7. Wiring `CollectCapsuleAugmentedContextTask` `@OutputFile provenanceFile`.
  8. Pas de config/DSL/4 sources — provenance always-on cheap.
  9. Économie d'encre `@OutputFile` UP-TO-DATE.
  10. JSON INDENT_OUTPUT (lisibilité auteur).
  11. Runner dédié `CapsuleProvenanceCucumberRunner` + steps préfixés
      "provenance" + `CucumberTaskSpec("cucumberTestProvenance")` 13ème.

. **MàJ gouvernance** — INDEX/BACKLOG/PROMPT_REPRISE/TODO. Zéro code modifié
