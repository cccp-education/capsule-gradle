== Décision de conception (durant GREEN)

Le cadrage (US-0 S-114) prévoyait `dependsOn("generateCapsuleContent")`. En
l'implémentant tel quel, les functional tests échouaient à la résolution du
task graph : `generateCapsuleContent` configure `deckFile` avec un provider qui
`error("No deck found")` en l'absence de deck. Deux options :
(a) fournir un deck dans les tests — inutile, la tâche transcript n'a pas
    besoin du deck, seulement des speaker notes ;
(b) garder le dependsOn en prod + `-x generateCapsuleContent` dans les tests
    qui pré-écrivent les speaker notes.

Option (b) retenue : le dependsOn reste conforme au cadrage (en prod,
`generateCapsuleContent` tourne d'abord), les tests restent standalone et
déterministes (zéro LLM involontaire, économie d'encre).
