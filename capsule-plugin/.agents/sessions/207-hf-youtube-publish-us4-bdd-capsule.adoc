== Contexte

L'US-3b (S-206) a livré le code de publication YouTube capsule
(`capsule.adapter.youtube` + `publishCapsuleToYouTube`) avec ses tests unitaires,
mais **sans BDD**. L'US-4 de l'EPIC transverse exige la parité d'acceptation entre

'''
== Baby-step DDD/TDD/BDD

=== 1. BDD — `@publish` (5 scénarios, transport factice)

* `capsule_publish.feature` :
  ** publication réussie → URL `https://youtu.be/VID` ;
  ** credentials incomplets → `Degraded` **sans aucune requête** (économie d'encre) ;
  ** jeton refusé → `Failed` ;
  ** publication désactivée → `Degraded` sans requête ;
  ** plateforme non supportée → `Degraded` sans requête.
* `CapsulePublishSteps` — steps **préfixés** `capsule publish …` (bug S-088, glue
  `capsule.scenarios` partagée). Le transport factice ne touche jamais le réseau ;
  le fichier de credentials est une fixture temporaire (aucun secret réel).
* `CapsulePublishCucumberRunner` — runner dédié (pattern S-082) +
  `CucumberTaskSpec("cucumberTestPublish")`.
* **Partition CI** : la feature est rattachée au shard `media`
  (`CucumberShardMediaRunner`) — la garde `CapsuleCucumberShardCoverageTest`
  exige une partition exhaustive/disjointe de **toutes** les features.

=== 2. Fonctionnel — `PublishCapsuleToYouTubeFunctionalTest` (TestKit)

Trois tests hermétiques, **zéro réseau** :

* la tâche `publishCapsuleToYouTube` est enregistrée dans le groupe `deploy` ;
* désactivée par défaut → rapport `publication.json` `skipped=true` ;
* activée avec une vidéo + un titre mais **sans** `youtube.yaml` → `degraded`
  (le resolver est atteint, échoue proprement, ne lève pas).

Le test est rattaché au shard fonctionnel `Functional · media`
(`full-tests.yml`) — la garde exige aussi une partition exhaustive/disjointe des
classes `*FunctionalTest`.

=== 3. Hygiène sécurité

* `.gitignore` : `youtube.yaml` + `client_secret_*.json` (fichiers OAuth téléchargés
  depuis Google Cloud) — jamais commités.
* `youtube_example.yaml` versionné (valeurs bidon) documentant le format attendu
  par `YouTubeCredentialsLoader`.
