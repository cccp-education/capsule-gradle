=== Défaut de nommage découvert + Fix TDD

Le dogfooding a révélé un défaut réel : le rendu produisait
`<deckName>_<lang>-deck.webm` (dérivé du header script
`=== CAPSULE SCRIPT : <deckName>_<lang>-deck ===`, flux réel slider SLD-11)
au lieu de la convention du plan `<deckName>_<lang>.webm` (`entry.outputVideo`).

Conséquence : l'économie d'encre (AGENT.adoc règle 2) ne se déclenchait jamais —
le probe `shouldRender` cherche `entry.outputVideo` qui n'existait pas (le
fichier produit portait un autre nom) → re-render systématique.

Fix baby-step TDD :

. *RED* : `CapsuleVideoOutputRenamerTest` (4 tests : rename quand noms diffèrent,
  no-op même path, no-op si rendu absent, création parent dir).
. *GREEN* : `CapsuleVideoOutputRenamer` (domaine `capsule.multilang`, object pur
  `rename(rendered, target): File` — no-op si absent/même path, sinon
  `renameTo` avec fallback `copyTo`+`delete`).
. *Wiring* : post-capture dans `GenerateCapsuleVideoAllLanguagesTask.renderEntry`
  après `captureDeckSequential/Parallel`, log d'alignement conditionnel.
. *Re-dogfooding* : alignement `-deck.webm` → `_<lang>.webm` logué pour les 3
  langues + économie d'encre prouvée (`--rerun-tasks` →
  `0/3 languages rendered, 3 skipped: existing valid WebM`).

== Décisions d'architecture

. *`CapsuleVideoOutputRenamer` est un object pur du domaine* — aligné sur la
  discipline DDD du projet (objects purs testables, pas de couplage Gradle).
  Le wiring impur (log, filesystem via le task) reste dans `renderEntry`.
. *Le contrat du plan (`entry.outputVideo`) est l'artifact autoritaire* — le
  WebM rendu par le pipeline mono-langue (nommé depuis le header script) est
  aligné sur le plan a posteriori, pas l'inverse. Cela préserve l'économie
  d'encre (le probe `shouldRender` matche le fichier existant).
. *Le flux réel slider SLD-11 produit des headers `<deckName>_<lang>-deck`* —
  divergence légitime entre le deckName du script (inclus `-deck`) et le
  deckName du plan (sans `-deck`). Le renamer résout cette divergence côté
  capsule sans modifier slider (boundary respecté).
