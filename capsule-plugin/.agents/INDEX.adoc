_Vision_ : La création de contenu assistée par IA dans capsule (scripts TTS, speaker
notes, traduction multi-langue) doit s'appuyer sur les hubs existants (`slider` pour
la génération de decks, `codebase` pour le RAG/vibecoding/LLM pool) plutôt que
d'éparpiller des appels LLM directs. L'i18n suit la même logique : `translateDeck`
