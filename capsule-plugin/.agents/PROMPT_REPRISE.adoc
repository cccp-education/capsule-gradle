== Mission Session 172 — au choix du pilote

=== Option A — CAP-QC-VOICE US-2 (cœur de l'EPIC en cours)

Port `SpeechRecognizer` + tâche `verifyCapsuleVoice`.
1. **Port** : `fun interface SpeechRecognizer { fun transcribe(audio: File, language: String): String }`
   + adapter CLI (`whisper`/`faster-whisper`), **jamais** dépendance dure ; binaire absent →
   dégradé.
2. **Cadres RMS** : extraire l'enveloppe (I/O) pour alimenter `SnrEstimator`.
3. **Tâche** `verifyCapsuleVoice` (groupe `verification`) : transcrit chaque `slide-NN.mp3`,
   `FidelityScorer.score`, écrit un **rapport JSON** ; échoue si `wordErrorRate >
   maxWordErrorRate` ou `surplus >= surplusThreshold` ou `snrDb < minSnrDb` ; dégradé si ASR
   absent ; `strictMode` → échec.
4. **Config** `VoiceConfig` (`verifyEnabled` false, `maxWordErrorRate=0.15`, `minSnrDb=66.0`,
   `surplusThreshold=3`, `asrExecutablePath`, `model`, `language`) sur les **4 sources** +
   push ; enregistrement `CapsuleManager`.
5. **Tests** : unit (scorer/tâche via seam) ; BDD `@voice-verify` (fakes, zéro ASR) ;
   functional TestKit (ASR absente → skip `assumeTrue`). **Jamais** l'ASR prérequis de `check`.

=== Option B — PRT-01 (clôt CAP-QC → 8/9, intrusif)

Prononciation « dit / lu » + cache par contenu : `capsule.voice.PronunciationLexicon` (pur) ;
`TtsEngine.synthesize` reçoit le **texte dit** ; cache indexé sur le texte dit → nom
`slide-NN-<key8>.mp3` ; lookup `CapsuleBuildTask`/`CapsuleVideoTask` ; `SubtitleTextNormalizer.reversals`
(round-trip). **Opt-in** (`tts.pronunciationEnabled`) pour ne pas casser le nommage
`slide-NN.mp3` et ses tests.

=== Option C — PRT-08 (planches QC visuelles)

`capsule.qc` + rendu Java2D : planches « beats » (état final de chaque slide) et « dit vs
montré » (image du master à ~60 % d'une prise + texte dit). S'appuie sur `capsule.timeline`
(PRT-07) et les sous-titres (PRT-03).
