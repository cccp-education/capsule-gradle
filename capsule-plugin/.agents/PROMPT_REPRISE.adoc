== Points d'attention

* **Local = Build, Tests = CI** : ne jamais lancer `test`/`check` en local.
* Nouvelle option → `Config` + extension + `CapsuleConventions` + merger (4 sources) +
  `pushConfigIntoExtension`, **défaut false** (backward compat).
* English only (`OssVocabularyGuardTest`) ; zéro Python ; zéro secret ; baby-step
  DDD/TDD/BDD ; runner dédié par feature (S-082), steps préfixés (S-088).
* Les tâches consommateur ne s'affichent PAS dans l'auto-build du plugin — les valider
  via une functionalTest `GradleRunner`.
* L'ASR n'est **jamais** un prérequis de `check` (`isAvailable` + dégradation + `assumeFalse`).
