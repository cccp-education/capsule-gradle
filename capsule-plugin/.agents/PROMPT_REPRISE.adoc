== Points d'attention

* **Local = Build, Tests = CI** : ne jamais lancer `test`/`check` en local.
* Nouvelle option → `Config` + extension + `CapsuleConventions` + merger (4 sources) +
  `pushConfigIntoExtension`, **défaut false** (backward compat, zéro régression).
* English only (`OssVocabularyGuardTest`) ; zéro Python ; zéro secret ; baby-step
  DDD/TDD/BDD ; runner dédié par feature (S-082), steps préfixés (S-088).
* La CI agrégée (`cucumberTest`, S-163) exécute automatiquement toute nouvelle feature.
* Rappel : les tâches consommateur (`preflightCapsuleContent`, etc.) ne s'affichent PAS
  dans le build du plugin lui-même (il n'applique pas `education.cccp.capsule`) — les
  valider via une functionalTest `GradleRunner` ou un projet consommateur.
