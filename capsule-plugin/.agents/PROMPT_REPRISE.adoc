== Session 209 (TERMINÉE) — CAP-AUDIO-SILENCE US-1

Un take **muet** (NoOp TTS, export audio cassé) échoue désormais
`verifyCapsuleVoice` avec `silent-audio`, **même sans ASR** — la détection est
indépendante du recogniser.

Livré (baby-step DDD/TDD/BDD) :

* domaine pur `capsule.voice.AudioSilenceDetector` + `SilenceAnalysis`
  (`isSilent` sur le pic RMS, `silentFraction` diagnostique, seuil
  `DEFAULT_RMS_THRESHOLD = 0.001`, envelope vide = silence) ;
* `VoiceQualityGate.REASON_SILENT_AUDIO` + paramètre `silence` optionnel ;
* `VoiceVerifier.verify` réutilise l'enveloppe (SNR + silence) ; `degraded`
  accepte un `envelopeProvider` et marque un take muet `Fail(["silent-audio"])`
  tout en gardant `degraded = true` ;
* `VerifyCapsuleVoiceTask` vérifie `hasFailure` **avant** le retour dégradé ;
  `snrDb = null` sur silence (plus de `-Infinity`) ;
* tests : 7 unit `AudioSilenceDetectorTest`, +2 `VoiceQualityGateTest`, +4
  `VoiceVerifierTest`, +2 scénarios `@voice-verify`, +1 TestKit (audio muet réel
  ffmpeg, skip-gardé) ;
* RED prouvé : 19 erreurs `compileTestKotlin` avant production.
