[.slide,data-transition="slide"]
== Le contrat capsule-gradle

[%step]
* Format plain-text delimite
* En-tete: `=== CAPSULE SCRIPT : nom ===`
* Un segment par slide: `--- SLIDE n : titre ---`
* Corps: note orateur telle quelle

[NOTE.speaker]
--
Le contrat entre slider et capsule est volontairement simple :
un fichier texte avec un en-tete et un segment par slide.
Chaque segment contient la note orateur qui deviendra la narration TTS.
--

[.slide,data-transition="slide"]
== Validation round-trip

[%step]
* Le parser extrait les segments depuis l AsciiDoc
* Le writer serialize vers le contrat plain-text
* Capsule-gradle re-parse le meme format
* Zero perte : ce que slider ecrit, capsule lit

[NOTE.speaker]
--
Le round-trip est valide : le parser extrait les segments depuis la source
AsciiDoc, le writer les serialise vers le contrat plain-text,
et capsule-gradle re-parse le meme format sans aucune perte de donnees.
--
